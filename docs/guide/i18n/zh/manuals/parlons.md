## 1. Parlons 是什么

Parlons 是一款私密聊天应用，中间没有任何公司。

- **无需注册**。不需要电话号码，不需要电子邮箱，不需要在任何地方开账户。
- 您的消息在离开设备之前就已**在设备上封装加密**。只有收信人才能打开。
- 封装后的消息由像您一样的普通人运行的**中继**传送。中继无法读取消息内容。
- 您的身份就是 **24 个词**。这些词同时也是一个 **Minima 钱包**。谁掌握这些词，谁就是您。

您可以用它来：

- 一对一聊天，以及最多 12 人的群组。
- 发送照片、语音消息和名片。
- 私密文件，最大 512 MB，加密后直接在聊天成员之间传送。
- 语音和视频通话（Android）。
- 在聊天中发送 Minima 或 **MxUSD**（Minima 美元代币）。
- 使用英语、简体中文、俄语或乌克兰语界面。

Parlons 是开源的，由社区运营。没有客服中心，因为根本没有公司账户可查。本手册、应用内的“这是什么？”说明以及问题跟踪页面就是支持渠道。

## 2. 工作原理

使用 Parlons 不需要了解这些内容，但出问题时会有帮助。

### 您的设备没有固定地址，所以要借一个

连接 Wi-Fi 或移动数据的手机通常无法接受传入连接。所以 Parlons 会主动**向外**连接几个中继（应用中也称为**主机**）。每个中继都会保持这条连接。所有发给您的内容都会沿着这条连接传回来。

- **已连接**表示至少有一个中继正在为您保持连接。
- **未连接**表示此刻没有人能联系到您。您仍然可以写消息，中继恢复后消息就会发出。

Parlons 会**同时连接多个中继**。其中一个断开时，其他中继仍会为您传送消息。

### 消息端到端封装加密

每条消息都在发送者的设备上用收信人的密钥加密，并由发送者签名。中继只能看到一个封装好的数据块和一个路由密钥。它能知道有人在向某个密钥发送内容，但永远无法知道内容是什么。

### 发给离线用户的消息会等待对方上线

如果收信人离线，封装好的消息会存放在**邮箱**中，直到对方回来。应用也会把您自己尚未发出的消息保存在**发件箱**中，并不断重试。

### 勾号如实告诉您状态

| 标记 | 含义 |
|---|---|
| ⋯（正在发送…） | 已排队，还没有交给中继。 |
| ✓ 一个灰色勾号（已发送，中继已接收） | 一个中继接收了这条消息。 |
| ✓✓ 两个灰色勾号（已送达） | 对方自己的设备确认已收到消息。在群组中，表示每位当前成员都已收到。 |
| ✓✓ 两个蓝色勾号（已读） | 对方已阅读。只有对方开启了已读回执才会显示。 |
| ✗（发送失败） | 没有中继愿意接收。消息留在您的发件箱中，并会重试。 |

两个勾号来自收信人的设备本身，而不是中继。所以您可以信任它们。

## 3. 我需要哪个应用？

只需回答一个问题：您想在**这台设备**上聊天，还是想**在所有设备上使用同一个账户**？

| 您想要 | 使用 | 说明 |
|---|---|---|
| 在 Android 手机上聊天 | **Parlons!**（Android 应用） | 您的身份保存在手机上。需要 Android 9 或更高版本。 |
| 在电脑上聊天 | **Parlons Desktop** | Mac、Windows、Linux。您的身份保存在电脑上。自带 Java。 |
| 在手机和笔记本电脑上使用相同的聊天，或使用 iPhone | 一个 **Parlons 账户**，加上每台设备上的 **Parlons Cloud** | 账户运行在一台始终开机的机器上。请参阅[第 21 节](#21-one-account-on-every-device-parlons-cloud-your-own-account-hosted-accounts)。 |

> **重要：**Android 应用和 Parlons Desktop 各自拥有**独立**的身份。如果您两个都安装，并在每个上面都创建身份，您会得到两个不同的地址。要在两个地方使用同一个身份，请使用 Parlons 账户。切勿在两台同时运行的设备上恢复同一组 24 个词。

### 各应用的功能

| 功能 | Android 应用 | Parlons Desktop |
|---|---|---|
| 聊天和群组 | 支持 | 支持 |
| 照片 | 支持，包括相机拍摄 | 支持，包括从剪贴板粘贴 |
| 语音消息 | 支持（最长 60 秒） | 支持 |
| 私密文件（最大 512 MB） | 支持 | 支持 |
| 语音和视频通话 | 支持 | 不支持。来电会显示并被礼貌地拒绝。请在手机上接听。 |
| 发送 Minima 或 MxUSD | 支持 | 支持 |
| 钱包标签页 | 支持 | 支持 |
| 扫描二维码 | 支持 | 没有相机。请改为粘贴地址。 |
| 加密身份备份文件 | 支持 | 不支持。请保管好您的 24 个词。 |
| 应用锁（指纹或 PIN） | 支持 | 不支持 |
| 文字大小快捷键 | 不支持 | 支持 |

Parlons Cloud Android 版也可以为已配对的账户拨打和接听电话、发送付款。Parlons iPhone 版目前还不支持通话，也不能发送付款。

## 4. 安装

### 4.1 Android

您需要一部运行 **Android 9 或更高版本**的 Android 手机，以及纸和笔。

Parlons **不在 Play 商店中**。它是直接下载的，由作者签名。

1. 在手机上打开发布页面：<https://github.com/eurobuddha/maxima/releases>
2. 找到 Parlons Android 版 **0.6.145**，点按其 `.apk` 文件进行下载。
3. Android 会询问是否允许从浏览器安装应用。为这次安装选择允许。之后可以在“设置”>“应用”>“特殊应用权限”>“安装未知应用”中再次关闭。
4. 点按**安装**，然后点按**打开**。

如果您的手机上已经在使用 PandaApps 应用商店，那里也有 Parlons!，并可以通过它更新。

**更新。**直接在旧版本上安装新的 APK。您的身份、联系人和聊天都会保留。

### 4.2 Mac

1. 从发布页面下载 Parlons Desktop **1.5.115** 磁盘映像（`.dmg`）。它已签名并经过公证，macOS 打开时不会弹出警告。
2. 打开磁盘映像，将 **MaximaNode** 拖到“应用程序”中。
3. 从“应用程序”中打开它。它自带 Java，无需安装其他任何东西。

需要搭载 Apple 芯片的 Mac（M1 或更新机型），macOS 13 或更高版本。磁盘映像仅为 arm64 构建。

**更新。**用新的磁盘映像覆盖安装旧应用。您在 `~/.maxima` 中的数据会保留。

### 4.3 Windows

1. 从发布页面下载 Parlons Desktop **1.5.115** 安装程序（`.msi`）。
2. 运行它。Windows 可能会显示一个蓝色的 **Windows 已保护你的电脑**窗口，因为该安装程序尚未使用 Microsoft 证书签名。点击**更多信息**，然后点击**仍要运行**。
3. 选择一个文件夹，默认即可。它只为您当前的用户安装，不需要管理员权限，并会把 Parlons 添加到“开始”菜单。它自带 Java。

需要 64 位 Windows 10 或 11。

**更新。**在旧版本上运行新的安装程序。您的数据会保留。

### 4.4 Linux

Parlons Desktop 是适用于 Debian、Ubuntu 及其衍生发行版的 64 位 x86 软件包。它自带 Java。

1. 从发布页面下载 Parlons Desktop **1.5.115** `.deb` 软件包。
2. 在终端中，进入保存该文件的文件夹，运行：

   ```
   sudo apt install ./maximanode_1.5.115_amd64.deb
   ```

3. 从应用程序菜单中打开 **MaximaNode**。启动程序位于 `/opt/maximanode/bin/MaximaNode`。

桌面应用没有 ARM 版本。在树莓派上，请改为运行一个 Parlons 账户（[第 21 节](#21-one-account-on-every-device-parlons-cloud-your-own-account-hosted-accounts)）。

**更新。**在旧版本上安装新的软件包。您在 `~/.maxima` 中的数据会保留。

### 4.5 iPhone

iPhone 应用是 **Parlons Cloud iPhone 版**。它本身不保存身份，而是与一个 Parlons 账户配对。Apple 不允许应用在后台保持可被连接的状态，所以这是 iPhone 在应用关闭时接收消息的唯一方式。

iPhone 应用**尚未推出**：它不在 App Store 中，也没有可下载的测试版本。它将需要 iOS 17 或更高版本。在此之前，请在 Android 或电脑上使用 Parlons。配对将如何进行，请参阅[第 21 节](#21-one-account-on-every-device-parlons-cloud-your-own-account-hosted-accounts)。

## 5. 首次运行：您的身份

### 5.1 Android

1. **选择语言。**第一次打开 Parlons 时，会出现一个标题为 **Language · 语言 · Язык · Мова** 的窗口。点按您的语言。以后可以更改。
2. 欢迎屏幕显示 **Parlons!**，并提供以下选项：
   - **创建新身份**
   - **通过助记词恢复**
   - **更改语言**

#### 创建新身份

1. 点按**创建新身份**。
2. 出现一个标题为**请记下这 24 个词**的窗口。这些词带有编号。此屏幕禁止截图。
3. 把全部 24 个词连同编号，**按顺序**写在纸上。
4. 对照屏幕逐个核对每个词。
5. 确认写好之后，再点按**我已保存**。

屏幕上有一个**复制**按钮。它会把这些词放到剪贴板上，并在 60 秒后清除。尽量不要使用它。其他应用可以读取剪贴板，剪贴板管理器也可能保留一份副本。

> 这是恢复您的身份和资金的**唯一**途径。请把这张纸离线、私密地保管。任何拿到这些词的人都可以冒充您。

#### 恢复已有的身份

仅当原来保存这些词的设备**已不再运行** Parlons 时才使用此功能。一个身份同一时间只能在一个地方使用。

1. 点按**通过助记词恢复**。
2. 在**请输入助记词**中输入或粘贴您的短语。此屏幕禁止截图。
3. 如果您的短语来自 Minima 的“anyphrase”模式（自定义短语，而不是 24 个标准单词），请勾选**自定义短语（Minima anyphrase）**。然后**完全按原样**输入，每个大写字母和空格都要与原来一致。
4. 点按**恢复**。
5. 您会看到**您的身份已恢复到此手机。**点按**开始**。

您可能还会看到以下提示之一：

- **“注意：没有 BIP39 校验和，这对于来自 Minima 节点的短语是正常的。已完成恢复。”**对于来自 Minima 节点的短语，这是正常的。
- **“已按原样恢复您输入的自定义短语。”**您使用了自定义短语模式。

恢复窗口还会提醒您注意**密钥使用次数**。您的钱包使用一次性密钥签名。仅凭这些词无法得知已经用掉了多少个密钥。如果这个短语曾在其他钱包或节点上签署过交易，请先检查清楚，再从 Parlons 发送资金。完整的加密备份（[第 20 节](#20-backups-and-moving-to-a-new-device)）带有真实的使用次数。

> 助记词只能恢复您的**身份**，不能恢复旧的聊天记录或联系人。您的联系人仍然可以联系到您，因为您的地址没有变。

#### 第一个屏幕之后

1. Android 会请求允许向您发送通知。**请允许。**否则您将看不到新到的消息。
2. 打开**设置**：点按**三个点**（右上角），然后点按**设置**。在**节点与电源**下，查看**电池优化豁免**。如果显示**未设置**，点按**调整电池设置**，并允许 Parlons 不受限制地运行。Android 会结束后台应用，对聊天应用来说，这意味着会漏掉消息，尤其是在夜间。
3. 在**设置**中的**您的名称**下，输入您希望联系人看到的名字，然后点按**设置**。名字最多 32 个字符。

### 5.2 Parlons Desktop

1. 打开 **MaximaNode**。
2. 应用会创建您的身份，并显示一个标题为**备份您的 Maxima 助记词**的窗口，其中有“您的 Maxima 节点创建了一个新身份。”的提示，以及您的 24 个词。
3. 现在就按顺序把它们写下来。
4. 这些词也会保存在一个只有您的用户账户才能读取的文件中：

   | 系统 | 助记词文件 |
   |---|---|
   | Mac | `~/.maxima/seed.txt` |
   | Linux | `~/.maxima/seed.txt` |
   | Windows | `C:\Users\<you>\.maxima\seed.txt` |

5. 您会进入**聊天**标签页。
6. 给自己起个名字。点击**三个点**按钮（右上角），它会打开**设置**。在**您的名称**下，在**显示名称**中输入您的名字，然后点击**设置**。

备份窗口只会在第一次启动时出现。如果您错过了，请参阅[第 18.2 节](#182-desktop-settings)再次显示这些词。

## 6. 应用导览

### 6.1 Android

顶部栏显示 **Parlons!**、版本号和一个状态标签。该标签显示您已连接的中继（主机）数量，或者显示**离线**。

顶部栏按钮：

| 按钮 | 作用 |
|---|---|
| 搜索（放大镜） | 搜索消息、联系人和群组。 |
| 主题 | 在系统、浅色和深色之间循环切换。会出现一条简短提示显示新的选择，例如“主题：深色”。 |
| 三个点 | 菜单：**新建群组**、**扫描二维码**、**搜索**、**设置**。 |

顶部栏下方有四个标签页。点按标签页，或左右滑动：

| 标签页 | 内容 |
|---|---|
| **聊天** | 您的对话，最新的在最前面。 |
| **联系人** | 您的地址卡片、您的联系人，以及 **+ 添加**。 |
| **钱包** | 您的 Minima 钱包：余额、代币、发送和接收、历史记录。 |
| **网络** | 连接状态、中继、协助网络、事件日志。 |

**设置**没有自己的标签页。其中包括语言、名字、隐私、外观、电源、密钥和备份。

#### 如何打开设置（Android）

1. 点按右上角的**三个点**。
2. 点按**设置**。

您也可以在**网络**标签页上再向左滑动一次。

#### 如何更改主题（Android）

1. 点按顶部栏中的**主题**按钮。
2. 每点按一次切换到下一个选项：系统、浅色、深色。

或者打开**设置**，进入**外观**，点按**系统**、**浅色**或**深色**。

许多卡片上都有**这是什么？**链接、**?** 或信息按钮。它会打开一段简短、通俗的说明。请多加利用。

### 6.2 Parlons Desktop

窗口有四个标签页：**聊天**、**联系人**、**钱包**、**网络**。顶部栏有一个**主题**按钮、一个**搜索**按钮和一个**三个点**按钮。底部显示“由 Maxima 提供支持”。

| 按钮 | 作用 |
|---|---|
| 主题（太阳或月亮） | 在浅色和深色之间切换。 |
| 搜索（放大镜） | 跳转到**聊天**标签页，并把光标放在**搜索聊天**中。 |
| 三个点 | 打开**设置**。 |

应用还会在菜单栏（Mac）或系统托盘（Windows、Linux）中放置一个图标。其菜单包括：

- **复制我的公网地址**
- **重新检查可访问性**
- **打开数据文件夹**
- **更改语言**
- **退出**

同一时间只能运行一个实例。如果您打开两次，会看到**“Maxima 已在运行。”**

#### 如何打开设置（桌面版）

1. 点击窗口右上角的**三个点**按钮。
2. **设置**页面随即打开。

#### 如何更改主题（桌面版）

1. 点击顶部栏中的**主题**按钮（太阳或月亮）。它会在浅色和深色之间切换。
2. 如果想跟随电脑本身的设置，请打开**设置**，进入**外观**，点击**系统**。

#### 如何更改文字大小（桌面版）

1. 按 **Ctrl +** 放大文字，或按 **Ctrl −** 缩小文字。在 Mac 上，**Command +** 和 **Command −** 也可以使用。
2. 每按一次调整一级。范围是 80% 到 150%。
3. 按 **Ctrl 0**（或 **Command 0**）恢复到 100%。

下次打开应用时会记住这个大小。

#### 如何使用托盘菜单（桌面版）

1. 点击菜单栏（Mac）或系统托盘（Windows、Linux）中的 Parlons 图标。
2. 选择一项：
   - **复制我的公网地址**会把您的完整地址放到剪贴板上。
   - **重新检查可访问性**会再次测试互联网能否连接到这台电脑。
   - **打开数据文件夹**会打开 `.maxima` 文件夹。
   - **更改语言**会打开语言列表。
   - **退出**会完全关闭应用。

## 7. 您的地址

您的地址是别人联系您的方式。它是一个公钥，而不是电话号码。

### 两种形式

| 形式 | 样子 | 会变吗？ |
|---|---|---|
| **当前地址** | `Mx<your key>@<host>:<port>` | `Mx` 部分永远不变。`@` 后面的部分是此刻为您传送消息的中继，当您的中继变化时它也会变化。系统会自动通知您的联系人。 |
| **永久地址** | `MAX#<key>#<location service>` | 永远不变，即使您在不同中继之间切换也一样。如果您有永久地址，请分享这个。 |

两种地址都很长。它们始终完整显示，您也应该始终完整复制。缩短的地址无法使用。

### 显示和分享您的地址（Android）

1. 打开**联系人**标签页。顶部的卡片上写着**您的 Parlons 地址**。
2. 点按**分享我的地址**。
3. 出现一个二维码，下方是您的完整地址。点按地址即可复制。
4. 点按**分享…**通过任何其他应用发送，或者让朋友扫描二维码。

如果您有永久地址，页面上会显示：“这是您的永久地址，即使更换主机也不会改变。”否则会显示您可以通过多少个中继被联系到。

如果您看到**“无法解析出可分享的 IP 地址。”**，请检查网络连接，然后重新打开该页面。

### 显示和分享您的地址（桌面版）

1. 打开**联系人**标签页。卡片上写着**您的 Maxima 地址**。
2. 点击**分享我的地址**。会打开一个窗口，其中有供手机扫描的二维码。
3. 二维码下方完整显示每个地址。有永久地址时，您会看到**永久 MAX# 地址**和**当前地址**。没有永久地址时，您会看到 **Maxima 地址**。点击地址即可复制。提示文字为**点击复制**。
4. 把它粘贴到电子邮件或任何其他消息中发给对方。

如果您看到“无法解析可分享的地址。请联网后重试。”，请检查网络连接，然后再次点击**分享我的地址**。

### 获取永久地址

永久 `MAX#` 地址来自**位置服务**（也称为 MLS）。它只回答一个问题：“这个身份当前的地址是什么？”

#### 如何获取永久地址（Android）

1. 打开**网络**标签页。
2. 找到卡片**位置服务 · 切换网络后仍可找到您**，点按**位置设置**。
3. 选择其中一项：
   - **使用 eurobuddha 中继池（注册）**。您会看到“已注册，您拥有永久 MAX# 地址”。
   - **将此地址设为永久地址**，固定您的中继为您提供的位置服务。
   - 自己输入一个位置服务（格式必须为 `Mx<key>@<host>:<port>`），然后点按**固定此 MLS**。
   - **使用主机目录**会恢复为默认设置。

#### 如何获取永久地址（桌面版）

1. 打开**网络**标签页。
2. 找到卡片**位置服务 · 切换网络后仍可找到您**。它显示您的**位置地址**及其**模式**：**静态（已固定）**或**轮换（由主机分配）**。
3. 点击**位置设置**。
4. 选择其中一项：
   - **使用 eurobuddha 中继池（注册）**。您会看到“注册成功，永久 MAX# 地址已启用”。
   - 输入格式为 `Mx<key>@<host>:<port>` 的位置服务，然后点击**固定此 MLS**。
   - **使用主机目录**会恢复为默认设置。

之后，您的永久地址会显示为**永久 MAX# 地址**。点击即可完整复制。

## 8. 添加联系人

添加某人是一次**握手**。您向对方的地址发送自我介绍。对方的设备回复后，对方就会出现在您的列表中。如果对方的设备关机，介绍会等待。

### 8.1 Android：扫描或粘贴

1. 打开**联系人**标签页，点按 **+ 添加**。
2. 选择以下任一方式：
   - 点按**扫描对方二维码**，将相机对准对方的屏幕。第一次需要允许使用相机。或者
   - 将对方的地址粘贴到输入框中（以 `Mx` 或 `MAX#` 开头）。
3. 点按**发送介绍**。
4. 您会看到**“介绍已发送，正在等待对方回复”**。

对方的设备一回复，对方就会出现在您的列表中。

您也可以点按**三个点**，然后点按**扫描二维码**。扫描到的地址会进入联系人标签页。

### 8.2 桌面版：粘贴

桌面版没有相机。别人扫描您，您粘贴别人。

1. 打开**联系人**标签页，点击**添加联系人**。
2. 粘贴对方的地址（`Mx<key>@<host>:<port>`，或永久形式 `MAX#<key>#<location service>`）。
3. 点击**发送介绍**。
4. 您会看到“自我介绍已发送。对方回复后会出现在这里。”

### 8.3 把联系人分享给其他人

您可以把一位联系人的地址作为**名片**发给另一位联系人。

#### 如何发送名片（Android）

1. 打开**联系人**标签页，点按您要分享的人。
2. 点按**发送给联系人…**。（旁边的**分享…**则是通过其他应用发送地址。）
3. 在**将 {name} 发送给…**中，点按要接收的人。
4. 您会看到“联系人已发送给 {name}”。

#### 如何发送名片（桌面版）

1. 打开**联系人**标签页，点击您要分享的人。
2. 点击**发送给联系人…**。
3. 点击要接收的人。

如果想自己复制地址，请在同一窗口中点击**复制分享地址**。

#### 如何通过名片添加联系人（Android）

1. 在聊天中点按名片。名片上写着**分享的联系人**和**点击添加此联系人**。
2. 一个窗口询问“添加 {name}？”，并显示对方的完整地址。
3. 点按**添加联系人**向对方发送介绍。或者点按**复制地址**完整复制该地址。
4. 您会看到“介绍已发送，对方回复后会显示在联系人中”。

### 8.4 联系人详情

在**联系人**标签页中点按（Android）或点击（桌面版）一位联系人。您会看到：

- **消息**，用于打开聊天。
- **Parlons 地址**（桌面版：**Maxima 地址**），以及可以联系到对方的每个主机（**主机 1**、**主机 2** …）。点按即可复制。
- **分享地址（永久）**，如果对方有永久地址。
- **分享…**（Android）或**复制分享地址**（桌面版），以及**发送给联系人…**
- **收款地址（MINIMA）**，在对方分享了钱包地址之后显示。
- **软件**，以及**上次在线**（或**当前在线**）。
- **移除联系人**。

#### 如何移除联系人（Android）

1. 打开**联系人**标签页，点按该联系人。
2. 向下滚动，点按**移除联系人**。
3. 一个窗口询问“移除 {name}？”。点按**移除**。

#### 如何移除联系人（桌面版）

1. 打开**联系人**标签页，点击该联系人。
2. 点击**移除联系人**。联系人会被立即移除，不会再次确认。

移除某人只会把对方从**您的**列表中删除。对方仍保留您的地址，仍然可以给您发消息。

#### 如何查找联系人

1. 打开**联系人**标签页。
2. 在搜索框中输入名字的一部分（Android 上为**搜索联系人**，桌面版上为**搜索**）。
3. 列表只显示匹配的联系人。

### 8.5 联系人旁边的状态文字

| 文字 | 含义 |
|---|---|
| 在线 / 当前在线 | 对方的设备现在可以联系到。 |
| 上次在线 … | 上一次收到对方设备消息的时间。 |
| 尚未连接 | 您已发送介绍，对方尚未回复。 |
| 暂无地址 | 没有对方的已知地址。 |
| 不在您的联系人中 | 您正在与一个不在您列表中的密钥聊天。 |
| 核心 / 经典 | 一个标签：表示始终在线的核心节点，或使用经典 Maxima 的用户。 |

使用经典 Maxima 的用户可以和您聊天，但不能接听电话，也不能播放语音消息。

## 9. 聊天

### 9.1 开始聊天

#### 如何开始聊天（Android）

1. 打开**联系人**标签页。
2. 点按该联系人。
3. 点按**消息**。

要回到已有的聊天，请打开**聊天**标签页并点按该聊天。

#### 如何开始聊天（桌面版）

1. 打开**聊天**标签页。
2. 点击圆形的**新聊天**按钮。
3. 在列表中点击该联系人。

或者打开**联系人**标签页，点击该联系人，然后点击**消息**。

新聊天会显示：“这是你与 {name} 的聊天开始。消息采用端到端加密，只有你们两人可以阅读。”

#### 如何发送消息

1. 打开聊天。
2. 在**消息**输入框中输入内容。
3. 点按（或点击）**发送**。在桌面版上也可以按 **Enter**。

#### 如何添加表情符号

1. 在聊天中，点按（或点击）**表情符号**按钮。
2. 选择一个分组：**笑脸**、**手势**、**爱心**、**动物与自然**、**食物与饮料**或**物品与符号**。
3. 点按一个表情符号，它会进入消息输入框。照常发送即可。

### 9.2 消息栏（Android）

从左到右：

| 控件 | 作用 |
|---|---|
| 表情符号 | 打开表情符号面板。 |
| 添加附件 | 打开菜单：**照片图库**、**私密文件**、**文件传输**、**语音消息**，以及**发送付款**（仅限一对一聊天）。 |
| 相机 | 拍摄一张照片并发送，可附加说明。 |
| 发送 / 麦克风 | 输入框中有文字时，用于发送。输入框为空时，显示麦克风，用于录制语音消息。 |

聊天顶部有**视频通话**、**语音通话**、一个主题按钮和一个**详情**按钮。在群组中，详情会显示成员。

#### 如何在聊天中查看联系人详情

1. 打开聊天。
2. Android：点按顶部的**详情**按钮。桌面版：点击对话顶部的名字。
3. 您会看到联系人的名字、完整密钥和地址。在群组中，您会看到**成员**，每位管理员旁边标有**（管理员）**。
4. 在 Android 上，点按**勾号代表什么？**可查看勾号的简短说明。看完后点按**关闭**。

### 9.3 长按消息（Android）

#### 如何复制、保存或查看消息（Android）

1. 长按消息气泡。
2. 点按其中一个选项。您只会看到适用于该消息的选项：
   - **复制消息**、**复制说明**或**复制联系人地址**。
   - **复制交易 ID**，用于付款消息。复制的是完整 ID。您会看到“交易 ID 已复制”。
   - **保存照片**或**分享照片**，用于照片。保存照片后会显示“已保存到照片”。
   - **详情**：谁发送的、何时发送，以及其状态（正在发送…、已发送（中继已接收）、已送达、已读、发送失败）。对于付款消息，详情还会显示完整的**交易 ID** 和一个**复制交易 ID** 按钮。

### 9.4 右键点击消息（桌面版）

#### 如何复制、打开或查看消息（桌面版）

1. 右键点击该消息。
2. 选择其中一项。您只会看到适用于该消息的选项：
   - **复制消息**、**复制说明**或**复制联系人地址**。
   - **复制交易 ID**，用于付款消息。复制的是完整 ID。
   - **打开图片**，用于照片。
   - **详情**。它显示谁发送的、**发送时间：**和**到达时间：**，以及其状态。迟到的消息会显示“发送于 … · 到达于 …”。

### 9.5 管理聊天

#### 如何将聊天标为已读

1. 打开**聊天**标签页。
2. 长按该聊天（Android）或右键点击它（桌面版）。
3. 选择**标为已读**。

#### 如何清空聊天

**清空消息**会删除该聊天中的所有消息，**仅限此设备**。它不会撤回任何消息，也不会退出群组。此操作无法撤销。

1. 打开**聊天**标签页。
2. 长按该聊天（Android）或右键点击它（桌面版）。
3. 选择**清空消息**。
4. 一个窗口询问**清空此聊天？**。点按**清除**（Android）或**确定**（桌面版）确认。

### 9.6 搜索

#### 如何搜索（Android）

1. 点按顶部栏中的放大镜。或者点按**三个点**，然后点按**搜索**。
2. 在**搜索消息…**中输入内容。
3. 结果分为**联系人和群组**和**消息**两组。点按某个结果即可打开。

#### 如何搜索（桌面版）

1. 点击顶部栏中的放大镜。应用会跳转到**聊天**标签页。
2. 在**搜索聊天**中输入内容。聊天列表只显示匹配项。
3. 点击某个结果即可打开。

### 9.7 已读回执

已读回执默认**已关闭**。送达状态（两个灰色勾号）始终开启，这是传输本身在正常工作。

#### 如何开启或关闭已读回执

1. 打开**设置**（Android：**三个点**，然后**设置**。桌面版：**三个点**按钮）。
2. 在**隐私**下，找到**已读回执**。
3. 打开或关闭开关。开启时，下方一行显示“联系人会获知您已读消息”。关闭时显示“联系人只能看到消息已送达，无法获知您何时阅读”。

此设置对所有人生效，不能针对单个联系人设置。

## 10. 群组

### 群组如何运作

群组消息会为每位成员**单独**加密，并分别发送给每个人。**没有共享群组密钥**。这意味着：

- 移除某人会立即生效。对方手里没有任何仍然有效的密钥。
- 某位成员的密钥被破解，也不会让整个群组暴露。
- 只有**管理员**可以更改群组成员。
- 只有当前成员才能发言。这一点在消息到达时就会检查，而不只是在应用中检查。

### 限制

| 限制 | 值 |
|---|---|
| 成员 | **包括您在内，最多 12 名成员。** |
| 通话 | 不支持群组通话。通话仅限一对一。 |
| 付款 | 付款仅限一对一。 |
| 私密文件 | 允许。只有当前成员可以参与。 |

如果您选择的人太多，会看到“一个群组包括您在内最多 12 人，请少选几位”。

### 创建群组（Android）

1. 点按顶部栏中的三个点，然后点按**新建群组**。
2. 在**选择群成员**下，勾选要加入的人。点按**下一步**。
3. 在**为群组命名**下，输入名称。点按**创建**。

您需要先至少有一位联系人。在选择界面中点按**群组如何运作**，可以查看上述规则。

### 创建群组（桌面版）

1. 在**聊天**标签页上，点击圆形的**新聊天**按钮。
2. 点击列表顶部的**新建群组**。
3. 在**群组名称**中输入名称。
4. 在**选择群成员**下，至少勾选一个人。
5. 点击**创建**。

在同一窗口中点击**群组如何运作**，可以查看上述规则。

### 更改成员

只有管理员可以执行此操作。您创建的群组，您就是管理员。

#### 如何更改成员（Android）

1. 打开群组，点按**详情**按钮。
2. 点按**编辑成员**。只有您是管理员时才会看到它。
3. 在**成员**中，勾选或取消勾选成员。
4. 点按**保存**。

#### 如何更改成员（桌面版）

1. 打开群组，点击对话顶部的群组名称。
2. 点击**编辑成员**。只有您是管理员时才会看到它。
3. 在**成员**中，勾选或取消勾选成员。
4. 点击**保存**。

在您担任管理员的群组中，您始终会保留在群里。如果您勾选的人太多，会看到 12 人上限的提示，并且不会做出任何更改。

没有“退出群组”按钮。如果不想再看到某个群组，请使用**清空消息**（[第 9.5 节](#95-manage-a-chat)），或请管理员将您移除。

## 11. 照片、语音消息和相册

### 大小限制

消息中的照片、语音消息或其他媒体**最大 16 MB**。文件过大时会显示“文件过大：单条消息最多可携带 16 MB”。更大的文件请使用**私密文件**（[第 12 节](#12-private-files)）。

### 发送照片（Android）

1. 在聊天中，点按**添加附件**，然后点按**照片图库**。或者点按**相机**按钮拍摄新照片。
2. 选择照片，或拍摄照片。
3. 在**发送照片**下，可以在**添加说明…**中添加说明（可选）。
4. 点按**发送**。您会看到“正在发送照片…”。

### 发送照片（桌面版）

#### 如何从文件发送照片（桌面版）

1. 在聊天中，点击**添加附件**，然后点击**照片…**。
2. 选择一个图片文件。
3. 在**发送照片**中，可以填写**说明（可选）**。
4. 发送。

#### 如何粘贴照片（桌面版）

1. 复制一张截图或图片，或在文件管理器中复制一个图片文件。
2. 点击对话区域。
3. 按 **Ctrl V**（Mac 上为 **Command V**）。会出现预览。
4. 如果需要，添加说明。
5. 选择**发送**或**取消**。

粘贴的图片在准备发送之前，剪贴板中的大小上限为 32 MB。普通文字的复制和粘贴照常使用。

### 相册

点按聊天中的任何照片，都会打开该对话中所有照片的相册，包括发送和接收的照片，按聊天顺序排列。

#### 如何浏览、保存和分享照片（Android）

1. 在聊天中点按一张照片，相册会从这张照片打开。
2. 左右滑动可切换到较新或较旧的照片。
3. 双指捏合可缩放，拖动可平移，双击可复原。
4. 点按**保存**将其保存到照片，或点按**分享**通过其他应用发送。
5. 如果照片显示“照片不可用 · 点按重试”，请点按它。
6. 使用返回按钮或关闭按钮离开相册。

#### 如何浏览和保存照片（桌面版）

1. 在聊天中点击一张照片，查看器会从这张照片打开。
2. 按左右方向键，或左右拖动，可在照片之间切换。
3. 使用鼠标滚轮缩放，拖动平移，双击复原。
4. 点击**保存图片**保存一份副本。
5. 按 **Escape** 关闭查看器。

相册是打开时的快照。如果在相册打开期间收到了新照片，请关闭后重新打开，才能看到它们。

### 语音消息

#### 如何录制语音消息（Android）

1. 在消息输入框为空的聊天中，点按**麦克风**按钮。或者点按**添加附件**，然后点按**语音消息**。
2. 第一次需要允许使用麦克风。
3. 开始说话。计时器和波形会显示录音情况。上限为 **60 秒**。
4. 点按**发送**或**取消**。

如果录音不到一秒，您会看到“录音太短，请再录一会儿”。

#### 如何录制语音消息（桌面版）

1. 在聊天中，点击**添加附件**，然后点击**语音消息**。
2. 如果电脑询问，请允许使用麦克风。窗口会显示 **●  正在录音** 和波形。
3. 开始说话。上限为 **60 秒**。达到上限时，录音停止，语音消息会被发送。
4. 点击**发送**或**取消**。

如果没有麦克风，您会看到“没有可用的麦克风。”

#### 如何播放语音消息

1. 点按（或点击）语音消息上的**播放**。
2. 再点按一次即可停止。

语音消息需要双方都使用 Parlons；使用经典 Maxima 的联系人无法接收语音消息。

## 12. 私密文件

私密文件让您可以在聊天中发送最大 **512 MB** 的文件。文件会用一个新的密钥加密，并以加密分块的形式**直接在对话成员之间**传送。没有中央服务器，也没有公开索引。

### 发送私密文件

#### 如何发送私密文件（Android）

1. 在聊天中，点按**添加附件**，然后点按**私密文件**。
2. 选择一个文件（最大 512 MB）。
3. 一个标题为**正在发送私密文件**的窗口会在加密文件期间显示“正在准备…”。点按**隐藏**可关闭窗口，处理会继续进行。

#### 如何发送私密文件（桌面版）

1. 在聊天中，点击**添加附件**，然后点击**私密文件…**。
2. 在**发送私密文件（最大 512 MB）**中选择文件。

聊天中会显示一张文件卡片，包含文件名和大小。

### 接收私密文件

接收**不会**自动开始，由您决定。

#### 如何接收私密文件

1. 点按（或点击）文件卡片。卡片上写着“点按“下载”接收此加密文件。在下载完成前，请确保至少一位参与者保持在线。”
2. 点按**下载**。
3. 等待。状态会依次变为**正在连接**、**正在下载**和**正在校验**。
4. 当显示**已完成**或**已就绪 · 正在分享**时，点按**保存文件…**。
5. 选择保存位置。您会看到“文件已保存”。

### 传输控制

#### 如何暂停、继续、保存或移除传输

1. 在聊天中，点按（或点击）**添加附件**，然后点按**文件传输**。您会看到此设备保留的所有传输。（也可以直接点按文件卡片。）
2. 点按（或点击）某个传输。
3. 使用您需要的控制：

| 控制 | 作用 |
|---|---|
| **暂停共享** / **继续** | 停止或重新开始此传输。 |
| **保存文件…** | 保存已完成的文件。 |
| **移除本地传输** | 删除此设备上的传输并停止共享。您已保存的副本会保留。操作前会先询问，请确认（在 Android 上按钮为**移除**）。 |

如果没有任何传输，您会看到“没有本地文件传输”。

在下载过程中，您的设备也可能向聊天中的其他人**上传加密分块**。这能帮助大家更快完成。

重新启动后，之前正在进行的传输会**自动继续**。您暂停的传输仍保持暂停。

### 状态文字

| 状态 | 含义 |
|---|---|
| 正在准备 | 正在加密文件。 |
| 等待其他节点 | 暂时还没有能联系到的、拥有该文件的人。 |
| 正在连接 / 正在下载 / 正在校验 | 进行中。 |
| 已就绪 · 正在分享 | 您已拥有该文件，并正在帮助其他人获取。 |
| 已就绪 · 已暂停 | 您已拥有该文件；共享已暂停。 |
| 已暂停 / 失败 | 已停止。点按**继续**重试。 |

### 限制和条件

| 限制 | 值 |
|---|---|
| 单个文件 | 512 MB |
| 设备上存储的传输数据 | 2 GB |
| 保留的传输数 | 32 |
| 同时进行的传输数 | 4 |

- **聊天中至少要有一个人可以被连接**，要么可以直接从互联网连接（[第 19 节](#19-the-network-tab-relays-and-helping-the-network)），要么在同一个局域网中。如果没有任何人可以被连接，传输会等待。没有中央服务器可以作为后备。
- **双方都需要支持私密文件的 Parlons 版本。**旧版应用会显示“私密文件 · 请更新 Parlons 后打开”。
- 一旦有人拿到了文件及其密钥，您就无法收回。
- 参与传输的人可以看到彼此的互联网地址。私密文件是加密的，但不是匿名的。

## 13. 语音和视频通话

通话可在 **Android 应用**和 **Parlons Cloud Android 版**中使用。Parlons Desktop 不传输通话音频或视频：它会显示来电（“请在手机上接听，桌面应用尚不支持通话音视频。”），并礼貌地拒绝，这样对方就不会一直响铃等待。桌面版上的**视频通话**和**语音通话**按钮只会显示这一说明。iPhone 应用目前还不支持通话。

### 拨打电话（Android）

1. 打开一个**一对一**聊天。
2. 在聊天顶部点按**语音通话**或**视频通话**。
3. 出现提示时，允许使用麦克风（视频通话还需允许相机）。
4. 屏幕会依次显示**正在呼叫…**、**正在连接…**，然后进入通话。

通话期间：

| 按钮 | 作用 |
|---|---|
| **静音** / **取消静音** | 您的麦克风。 |
| **扬声器** / **听筒** | 声音从哪里播放。 |
| **翻转** | 在前置和后置摄像头之间切换（视频）。 |
| **挂断** | 结束通话。 |

### 接听电话（Android）

来电会使用您的铃声响铃，并显示 **Parlons 来电**或 **Parlons 视频来电**。它可以显示在锁屏上。无人接听的来电大约 45 秒后停止响铃。

1. 点按**接听**接听电话，或点按**拒接**拒绝。
2. 如有提示，允许使用麦克风（视频通话还需允许相机）。
3. 按上文所述使用通话中的按钮。点按**挂断**结束通话。

#### 如何让来电在锁屏上响铃（Android）

1. 打开**设置**（**三个点**，然后**设置**）。
2. 在**隐私**下，找到**来电**。
3. 如果显示“允许全屏提醒，以在锁屏上显示来电”，请点按该行（显示**允许**），然后在打开的 Android 页面中允许。
4. 允许后，该行显示“铃声、振动和来电提醒”，并显示**设置**。点按它可选择铃声和振动。

### 通话限制

- 通话仅限**一对一**。“暂不支持群组通话”。
- 双方都需要使用 Parlons。“通话双方都需要使用 Parlons”。
- 通话会在两台设备之间建立**直接**连接。Parlons 不会通过中继服务器转发通话音频。某些网络（部分移动运营商、部分严格的路由器）会阻止直接连接。这时通话会显示**无法连接**或**通话无法连接**。请让一方或双方连接 Wi-Fi 后重试。

通话记录会出现在聊天中，例如“语音通话 · 2:35”、**未接来电**、**无人接听**、**对方忙线**，或“已在其他设备上接听”。

## 15. 付款：Minima 和 MxUSD

您的 24 个词也是一个 Minima 钱包。Parlons 可以发送两种货币：

- **Minima**，原生币。
- **MxUSD**，Minima 美元代币。其代币 ID 为：

  ```
  0x7D39745FBD29049BE29850B55A18BF550E4D442F930F86266E34193D89042A90
  ```

付款是**真实的**，并且**无法撤销**。交易**在您的设备上**构建和签名。只有签好名的交易会离开设备。

### 15.1 在聊天中向某人付款（Android）

1. 打开一个**一对一**聊天。群组中不能付款。
2. 点按**添加附件**，然后点按**发送付款**。
3. 在**向 {name} 付款**中，选择 **Minima** 或 **MxUSD**。
4. 在**金额（MINIMA）**或**金额（MxUSD）**中输入金额，并可填写**备注（可选）**。
5. 点按**发送**。确认窗口显示“发送 {amount} {token}？”和“此操作将签署并广播真实交易，无法撤销。”
6. 点按**确认**。您会看到“正在签署付款…”，然后是**付款已发送**。

聊天中会显示一个付款气泡。长按它并点按**复制交易 ID**，即可复制完整 ID。

如果您看到“尚无钱包地址，请对方打开此聊天”，说明对方的应用还没有把钱包地址分享给您。请对方打开与您的聊天。

### 15.2 在聊天中向某人付款（桌面版）

1. 打开与某位联系人的一对一聊天。点击**添加附件**，然后点击**发送付款**。
2. 窗口显示**发送给 {name}**。选择 **Minima** 或 **MxUSD**。
3. 输入**金额**，并可填写**备注（可选）**。
4. 点击**签名并发送**。

聊天中会显示“↑ 您已发送”或“↓ 您已收到”。右键点击该付款并选择**复制交易 ID**，即可复制完整 ID。

如果您看到“此联系人尚未提供钱包地址，需要先分享地址。”，请对方在其应用中打开与您的聊天。

### 15.3 钱包标签页

钱包标签页（Android 和桌面版）有两个视图：**余额**和**历史记录**。点按（或点击）顶部任一名称即可切换。

**余额**显示：

- 您的总余额和**当前可发送**的金额。仍在确认中的币暂时不能发送。
- **您的代币**（桌面版：**代币**），包括 MxUSD。
- **已用签名次数**：“剩余 {remaining} / {maximum} 次签名 · 每次发送消耗一次”。请参阅[第 15.4 节](#154-signature-uses-read-this-before-you-import-a-phrase)。
- **发送**和**接收**。

#### 如何解锁仍在同步的币（Android）

1. 打开**钱包**标签页。
2. 如果余额下方一行显示“可发送 … · 点按同步以解锁其余金额”，请点按这一行。
3. 您会看到“正在同步币…”，然后是“币已同步 — 当前可花费 …”。

#### 如何查看代币详情

1. 打开**钱包**标签页，进入**余额**。
2. 点按（或点击）**您的代币**（桌面版：**代币**）下的某个代币。
3. 您会看到它完整的**代币 ID**、**总供应量**和**币输出**。点按代币 ID 即可复制。

#### 如何接收 Minima 或 MxUSD

1. 打开**钱包**标签页。
2. 点按（或点击）**接收**。
3. **接收 MINIMA** 窗口会显示您完整的 Minima 地址和一个二维码。
4. 点按（或点击）地址复制完整字符串，或让付款人扫描二维码。

任何人都可以向这个地址发送 Minima 或 MxUSD。

#### 如何发送到某个地址（Android）

1. 打开**钱包**标签页，点按**发送**。
2. 在输入框中输入地址（以 `Mx` 或 `0x` 开头），或点按扫描按钮进行扫描。
3. 选择 **Minima** 或 **MxUSD**。
4. 输入金额。
5. 点按**签名并发送**。您会依次看到“正在选择币输出…”、“正在此设备上签名…”、“正在通过…发布…”，然后是“已发送 — 正在打包进区块”。

#### 如何发送到某个地址（桌面版）

1. 打开**钱包**标签页，点击**发送**。
2. 将地址粘贴到 **Mx… 地址**中。
3. 选择 **Minima** 或 **MxUSD**。
4. 输入**金额**。
5. 点击**签名并发送**。您会看到“正在选择币输出…”，然后是“正在通过…发布…”。

“正在打包进区块”是正常的。付款进入区块后即被确认。

#### 如何查看付款历史

1. 打开**钱包**标签页，点按（或点击）**历史记录**。
2. 点按**全部**、**已发送**或**已接收**筛选列表。
3. 点按某笔付款。您会看到其**方向**、**金额**、**代币**、**时间**、完整的**接收地址**或**发送地址**，以及完整的**交易 ID**。

### 15.4 签名使用次数：导入短语之前请先阅读

Minima 钱包使用一次性密钥签名。每个密钥只能签名有限的次数。Parlons 会记录使用次数，确保不会重复使用。重复使用一次性签名密钥可能会暴露密钥，导致资金损失。

- 计数器**只增不减**。
- 每次签名都会预留一次使用，即使付款没有完成。
- 仅凭助记词恢复，无法知道以前的计数。加密备份（[第 20 节](#20-backups-and-moving-to-a-new-device)）带有该计数。

#### 如何调高签名计数器（Android）

只有当您知道这个助记词在其他地方签名过更多次时，才这样做。

1. 打开**钱包**标签页，进入**余额**。
2. 长按**密钥使用次数**卡片（卡片上写着**已用签名次数**和**长按调整**）。
3. 在**设置已用签名次数**中，输入一个数字，至少要等于这个助记词在任何地方用过的次数。
4. 点按**设置**。您会看到“已设为 …”。

您不能调低它。输入较小的数字会显示“未更改 — 只能调高至大于 … 的值”。点按**取消**可以改为阅读**为何这很重要**。

在桌面版上，点击**已用签名次数**旁边的 **?**（**关于签名使用次数**）可查看相同的说明。桌面版钱包没有调高计数器的控件。

### 15.5 钱包设置（Android）

打开**钱包**标签页，滚动到底部，点按**钱包设置**。页面会显示钱包当前使用的是哪个助记词。

#### 如何使用您自己的钱包节点（Android）

默认情况下，钱包通过 Parlons 的 Minima 节点群读取链上数据，并会自动故障切换。您也可以把它指向您自己的 Parlons Node。您的助记词永远不会离开手机。

1. 在**钱包设置**中，点按**钱包节点**。
2. 在第一个输入框中输入您节点的端点（类似 `https://your-node…/cmd`），在第二个输入框中输入其**访问令牌**。
3. 点按**保存节点**。您会看到“钱包节点已保存”。

要撤销，请再次打开**钱包节点**，点按**重置为 Parlons 节点群**。端点和令牌请参阅[Parlons Node 手册](parlons-node.md#14-the-wallet-gateway-and-its-token)。

#### 如何导入其他钱包短语（Android）

这会用另一个 12 或 24 个单词的短语替换钱包的助记词。地址和资金都会改变，但您的聊天身份不会改变。只导入其密钥**未曾**在其他钱包或节点上签名过的短语。

1. 在**钱包设置**中，点按**导入助记词**。
2. 在**导入钱包助记词**中，阅读警告。
3. 在 **12 / 24 个单词的助记词**中输入短语。
4. 点按**导入**。您会看到“正在导入钱包助记词…”。

#### 如何切换回您的 Parlons 助记词（Android）

1. 在**钱包设置**中，点按**使用 Parlons 助记词**。
2. 一个窗口询问**使用 Parlons 助记词？**。点按**使用 Parlons 助记词**。
3. 您会看到“正在切换回 Parlons 助记词…”。

导入的钱包不会被删除。再次导入它的短语即可切换回去。

### 15.6 付款问题

## 19. 网络标签页：中继与协助网络

您不需要动这个标签页。它的作用是让您看到正在发生什么，并在需要时进行修复。

### 19.1 连接（Android）

顶部卡片显示**可连接**、**正在启动**或**离线**，以及**已连接主机**：此刻为您传送流量的中继。“可连接到您的独立路径。路径越多越可靠。”

其他计数器：

| 计数器 | 含义 |
|---|---|
| 您的发件箱 | 等待中继接收的您的消息。如果这个数字一直不减少，说明没有可连接的中继。 |
| 为他人保存的邮箱 | 此手机为离线用户保存的加密消息。它无法读取这些消息。 |
| 您提供的服务 | 此手机为他人回答的查询和回执。 |

点按任意计数器可查看简短说明。

#### 如何快速重新连接（Android 和桌面版）

1. 打开**网络**标签页。
2. 点按（或点击）顶部卡片中的**自动连接**。运行时显示**正在处理…**。
3. 应用会尝试它已知的中继，然后尝试让您可以被直接连接。一条提示会告诉您通过多少个中继连接。

### 19.2 中继（主机）

Parlons 内置了一份中继列表，也会从网络中发现新的中继。

任何公共 Maxima 节点都可以用作中继，包括开启了 Maxima 的经典 Minima 节点。

#### 如何添加您信任的中继（Android）

1. 打开**网络**标签页，找到**主机 · 为您转发流量**。
2. 在**添加中继 主机:端口**输入框中输入 `host:port`，或粘贴中继二维码的文本。
3. 点按**添加并连接**。
4. 一个窗口询问**添加并连接？**。点按**连接**。传输会重新启动。您的聊天和钱包不受影响。
5. 几秒钟后，一个窗口显示**已连接**（如果中继还没有接受您，则显示**正在重新连接**）。点按**确定**。

如果要改为扫描中继的二维码：点按**管理**，然后点按**扫描中继二维码**，将相机对准二维码。

#### 如何管理您的中继（Android）

1. 打开**网络**标签页。在**主机 · 为您转发流量**下，点按**管理**。
2. **管理主机**页面列出**已配置的主机**。每个主机显示“内置”或“您添加的”，以及**已连接**或**空闲**。
3. 在某个中继旁边，点按：
   - **连接**，立即连接到空闲的中继。
   - **显示二维码**，分享该中继（见下文）。
   - **移除**，删除该中继。
4. 点按底部的**恢复默认设置**，恢复随应用提供的列表。

您必须至少保留一个中继。如果您尝试移除最后一个，会看到“请至少保留一个中继 — 移除此中继前，请先添加自己的中继”。

#### 如何关闭或开启内置中继（Android）

1. 打开**网络**标签页，点按**管理**。
2. 关闭**使用内置中继**。现在只会使用您添加的中继，或此手机记住的中继。
3. 再次开启，即可同时使用随应用提供的列表和您自己的中继。

如果您没有自己的中继，会看到“请先添加自己的中继 — 手机需要一个初始连接点”。

#### 如何分享中继（Android）

1. 打开**网络**标签页，点按**管理**。
2. 点按该中继旁边的**显示二维码**。
3. **分享中继**页面会显示一个二维码。任何人扫描它，都会把该中继添加到自己的中继中。完整文本位于下方的**分享文本**中；点按即可复制。

#### 如何添加和管理中继（桌面版）

1. 打开**网络**标签页。找到**主机 · 为您转发流量**。
2. 要添加中继，请在**添加中继 主机:端口**中输入 `host:port`（或粘贴中继二维码的文本），然后点击**添加并连接**。
3. 列表中的每个中继都显示“内置”、“您添加的”或“自动发现”。在旁边点击**显示二维码**分享，点击**连接**立即连接，或点击**移除**删除。
4. 使用内置中继开关。它显示“内置中继：开启（应用自带列表以及您添加的中继）”或“内置中继：关闭（仅使用您添加或此电脑记住的中继）”。
5. 点击**恢复默认设置**，恢复随应用提供的列表。

### 19.3 协助网络（Android）

只有足够多的人帮忙传送流量，Parlons 才能正常运作。在网络标签页上，**协助网络**开关默认为**开启**。它会在手机安全范围内尽量多做贡献，分为三个步骤，您可以随时查看：

| 步骤 | 含义 | 何时运行 |
|---|---|---|
| **正在贡献** | 为离线用户保存加密邮件、回答查询、签署送达回执、存储小块加密数据。 | 大部分时间。如果开启了**仅限 Wi-Fi**（默认开启），使用移动数据时会暂停高负载任务。电量低时暂停。 |
| **可直接连接** | 您的手机获得一个真实的公网地址，联系人联系您时可以少一跳。 | 仅在连接 Wi-Fi 并且正在充电时运行，而且您的路由器需要开放端口。 |
| **中继 ⚡** | 您的手机在端口 **9535** 上为他人传送封装好的流量。 | 仅在连接 Wi-Fi、正在充电且电量在 60% 或以上时运行。拔掉电源后停止。 |

这些都不会让您丢失消息。如果您的路由器不开放端口，您仍然会像往常一样通过中继保持可连接。应用会告诉您某个步骤为什么没有运行，例如“中继需要 Wi-Fi”、“接通电源以为他人中继”或“电量需高于 60% 才能中继”。

#### 如何开启或关闭协助网络（Android）

1. 打开**网络**标签页。
2. 在**协助网络**下，打开或关闭**协助网络**开关。
3. 开启后，查看开关下方的三个步骤：**正在贡献**、**可直接连接**和**中继 ⚡**。如果某个步骤没有运行，下方会有一条提示说明原因和处理方法，例如**打开 Wi-Fi 设置**。

#### 如何让高负载任务在移动数据下运行（Android）

1. 打开**网络**标签页。
2. 在**协助网络**下，关闭**仅限 Wi-Fi**。这一行会变为“在任何网络上运行高负载任务”。
3. 再次开启，即可让高负载任务仅在 Wi-Fi 下运行（“使用移动数据时暂停高负载任务”）。

#### 如何查看需要在路由器上设置什么（Android）

1. 打开**网络**标签页。
2. 找到卡片**此手机在网络中的位置 · 转发设置**。它会显示**此手机（局域网）**、**您的路由器**、**您的公网地址**，并在适用时显示**直接连接的路由器规则**和**中继路由器规则**。点按任意一项即可复制。
3. 点按**打开路由器管理页面**，在浏览器中打开您的路由器。

#### 如何设置手动端口转发（Android）

如果您的路由器不会自动开放端口，请使用此方法。

1. 打开**网络**标签页，找到**直接可达性 · 尽可能使用公网地址**。
2. 点按**设置手动端口转发**。**手动端口转发**页面随即打开。
3. 在**转发到此手机**下，您会看到本地地址和端口。默认端口为 **9536**。您可以在**要转发的端口**中更改。端口 9535 保留给中继模式使用。
4. 在路由器上添加一条规则，把该 **TCP** 端口转发到该本地地址。
5. 回到该页面，检查**您的公网 IP（自动查找）**。如果不正确，请更正。
6. 点按**启用并验证**。您会看到“正在验证 …”。如果成功，您会看到“可以直接连接到您”，网络标签页上的按钮会显示**手动端口转发 · 已开启**。

要停止，请再次打开该页面，点按**关闭手动转发**。

如果仍然失败，您的网络服务商很可能让许多家庭共用一个公网地址（运营商级 NAT）。任何端口转发都无法解决这个问题。您仍会通过中继保持连接。

### 19.4 协助网络（桌面版）

在您开启以下任一功能之前，您的电脑上不会有任何程序监听端口。在 Windows 上，防火墙会询问一次，请允许。

#### 如何让您的电脑可以被直接连接（桌面版）

1. 打开**网络**标签页，找到**直接可达性 · 尽可能使用公网地址**。
2. 点击**检查并启用直接连接**。Parlons 会向路由器申请一个公网端口，并在公布之前先从外部验证它可用。
3. 如果成功，会显示您的**公网地址**。按钮会变为**重新检查**。
4. 如果路由器拒绝，请设置手动端口转发（见下文）。

#### 如何设置手动端口转发（桌面版）

1. 在**网络**标签页上，点击**设置手动端口转发**。
2. 在**转发到此电脑**下，您会看到本地地址和端口。如有需要，可在**要转发的端口**中更改端口。端口 9535 保留给中继模式使用。
3. 在路由器上添加一条规则，把该 **TCP** 端口转发到该本地地址。
4. 检查**您的公网 IP（自动查找）**，或手动输入。
5. 点击**启用并验证**。您会看到“已启用，正在从外部验证 …”。之后按钮会显示**手动端口转发 · 已开启**。

要停止，请再次打开它，点击**关闭手动转发**。

#### 如何将您的电脑作为中继运行（桌面版）

1. 打开**网络**标签页，找到**协助网络**。
2. 开启**作为中继运行**。它会在端口 9535 上为他人传送封装好的流量，让网络更壮大。
3. 卡片会显示“正在通过端口 9535 转发他人的流量”，以及**已连接客户端**和**已转发消息**。

关闭开关即可停止。

### 19.5 事件日志

网络标签页底部有一个**事件日志**：记录传输所做的一切，最新的在最前面。出现问题时，它会告诉您原因。其中从不包含您的消息或您的助记词。

#### 如何查看或清除事件日志

1. 打开**网络**标签页，滚动到底部。
2. 查看**事件日志**。最新的一行在最上面。
3. 点按（或点击）标题旁边的**清除**即可清空。

## 21. 一个账户用于所有设备：Parlons Cloud、自己的账户、托管账户

这是一个简要概述。[Parlons Cloud 手册](parlons-cloud-portal.md)详细介绍手机应用。[Parlons Node 手册](parlons-node.md)介绍如何运行账户服务器。

### 什么是 Parlons 账户

**Parlons 账户**是一个始终运行的小程序。它让您的身份保持在线，保存您的联系人和聊天记录，在手机关机时接收消息，并让您配对的每台设备都看到相同的对话。它需要一台始终开机、能访问外网的机器：树莓派、家用电脑或小型服务器。它不需要端口转发。

获得账户有三种方式：

- **运行自己的账户。**在 Mac、Linux、树莓派或 Windows 机器上执行一条安装命令。它会输出您的地址和一个配对**邀请**。
- **使用托管账户。**运行主机的人为您创建账户，并给您一个邀请。
- **Parlons Node、minimaCore Desktop 或 minimaDesk** 也都自带一个账户。

### 配对手机

**邀请**是一个二维码，或一行以 `MAX#` 开头的文本，其中包含账户地址和一个一次性配对码。

#### 如何安装 Parlons Cloud（Android）

1. 在手机上打开发布页面：<https://github.com/eurobuddha/maxima/releases>
2. 找到标签为 `portal-v0.2.90` 的发布版本。
3. 点按文件 `parlons-cloud-portal-0.2.90-release.apk` 进行下载。
4. 如果 Android 询问，请允许从浏览器安装，然后点按**安装**和**打开**。

#### 如何配对手机

1. 打开 **Parlons Cloud**（Android）或 iPhone 应用。
2. 在第一个屏幕**在云端运行 Parlons** 上，点按**扫描配对二维码**并扫描邀请。或者把邀请粘贴到**账号地址或配对邀请**中。地址和配对码都会自动填好。
3. 点按**连接并配对**。您会看到“正在连接网络…”，然后是“已找到账号，正在配对…”。
4. 允许通知。
5. 在 Android 上，打开**设置**，如果**此设备**下提供**保持后台运行**，请点按它。

如果您没有配对码，请将**配对码**留空，然后点按**连接并配对**。应用会显示“已请求配对。请在已配对的设备上批准”。请在一台已配对的设备上批准（见下面的步骤）。

#### 如何批准等待配对的设备

1. 在一部已配对的手机上，打开**节点**标签页。
2. 滚动到**等待批准（N）**。每个条目都显示**有设备请求配对**，以及该设备的密钥。
3. 核对该密钥是否与新设备上显示的密钥一致。
4. 只有一致时才点按**批准**。

#### 如何从已配对的手机配对另一台设备

1. 在一部已配对的手机上，打开**节点**标签页。
2. 点按**配对我的其他设备**。
3. 如果应用询问**邀请设备**，请输入账户的管理员密码，然后点按**继续**。
4. 应用显示**新配对码已生成**。点按**复制邀请**，或点按**显示二维码**以二维码形式显示。
5. 在新设备上，按照[如何配对手机](#how-to-pair-a-phone)操作。

[Parlons Cloud 手册](parlons-cloud-portal.md#10-adding-more-devices-owner-invitations)介绍了管理员密码。

#### 如何撤销丢失的设备

1. 在一部仍然配对的手机上，打开**节点**标签页。
2. 滚动到**已配对设备（N）**，找到丢失的设备。
3. 点按**撤销**。
4. 阅读**撤销此设备的访问权限？**，然后点按**撤销**。

#### 如何取消此手机的配对

1. 在 Parlons Cloud 中，点按**更多**，然后点按**取消此设备的配对**。
2. 阅读**取消此设备的配对？**，然后点按**取消配对**。应用会返回第一个屏幕。
3. 在另一台已配对的设备上，撤销此手机的条目（[如何撤销丢失的设备](#how-to-revoke-a-lost-device)）。

您的账户和身份仍保留在账户所在的机器上。

### Parlons Cloud 显示的内容

- **聊天**和**联系人**，与 Android 应用相同。您的地址显示为**我的 Parlons Cloud 地址**。它在每台设备上都相同。
- **节点**：账户的运行时间、中继、已配对设备（可**撤销**丢失的设备）、等待批准的设备，以及用于生成新配对码的**配对我的其他设备**。
- **设置**：名字、已读回执、应用锁、通知、手机启动时使用的中继、**显示助记词**、**备份账户…**（整个账户的加密 `.pbk` 备份，包括聊天记录），以及**导入身份或备份…**。

Parlons Cloud 每个屏幕的分步说明，请参阅[将应用与您的账户配对](parlons-cloud-portal.md#4-pair-the-app-to-your-account)以及 [Parlons Cloud 手册](parlons-cloud-portal.md)的其余部分。

### 托管账户：主机能做什么、不能做什么

- 主机**无法**读取传输中的消息。
- 主机**可以**读取其机器上存储的内容，包括您的聊天记录。请像选择替您保管信箱的人那样，选择一个您信任的主机。
- 您可以随时离开。备份账户，然后在您自己的机器上恢复。您的地址保持不变。

托管的访客账户**仅支持聊天、通话和文件**：没有钱包、终端或主机控制功能。

#### 如何备份 Parlons 账户

1. 在 Parlons Cloud 中，点按**更多**，然后点按**设置**。
2. 在**密钥与备份**下，点按**备份账户…**。
3. 输入至少 6 个字符的密码短语，输入两次。如果忘记，将无法找回。
4. 点按**创建备份**，然后选择 `.pbk` 文件的保存位置。

要把账户迁移到您自己的机器上，请按照[如何在您自己的机器上恢复账户](parlons-cloud-portal.md#how-to-restore-an-account-on-your-own-machine)操作。

## 22. 安全与隐私

### 您的 24 个词

- 它们是您的身份，**也是**一个 Minima 钱包。任何看到它们的人都可以冒充您，并花掉您的资金。
- 在它们显示时写在纸上。把这张纸离线保管。
- 切勿拍照、通过电子邮件发送，或输入到其他应用或网站中。
- 除了恢复时，Parlons 从不索要它们。Parlons 方面也永远不会有人向您索要。
- 一个身份同一时间只能在一个地方运行。在第一台设备仍在运行时，在第二台设备上恢复同一组助记词，会让您的联系人混乱，还可能重复使用绝不能重复使用的钱包密钥。

### Parlons 保护什么

- **消息内容。**端到端封装加密，并由发送者签名。中继只能看到一个封装好的数据块和一个路由密钥。
- **群组。**每条消息都为每位成员单独加密。
- **伪造。**只有签名与发送者匹配的消息才会被接受。
- **重放。**重复和过期的消息会被拒绝。
- **显示助记词的屏幕。**助记词、恢复和备份屏幕禁止截图。

### Parlons 无法防范什么

- **有人拿着您已解锁的设备。**设备上保存的聊天可以在那台设备上被读取。请使用设备锁，在 Android 上还可以使用**应用锁**。
- **有人掌握了您的 24 个词。**他们就是您。
- **主机读取其机器上存储的内容**，适用于托管账户。
- **中继进行的流量分析。**中继知道哪些路由密钥在与它通信，但不知道内容是什么。使用多个中继（Parlons 正是这样做的）可以限制任何单个中继能看到的信息。
- **直接连接会暴露 IP 地址。**通话、私密文件和直接连接会让设备之间直接相连，因此对方可以看到您的互联网地址。
- **您添加的联系人。**只添加您真正想添加的人。

### 隐私

作者**不收集任何数据**。没有统计分析，没有崩溃报告服务，没有广告标识符，没有跟踪，没有第三方 SDK，也没有需要注册的账户。

- Android 应用和 Parlons Desktop 把您的身份、联系人和聊天保存在设备上。
- 手机上的 Parlons Cloud 只保存一个设备密钥和一份缓存，其余内容都由账户保存。
- **iPhone 唤醒途径。**iOS 无法保持后台连接。当 iPhone 应用关闭时，您的账户会通过应用发布者运行的一个小型中继，向 Apple 推送服务发送一条不含内容的唤醒信号（“消息”或“通话”，不含发送者、收件人或文字）。您可以在 iPhone 应用的“设置”>“通知”中关闭它。

## 23. 故障排除

### 常见问题的分步解决方法

#### 如何解决消息延迟到达（Android）

1. 打开**设置**（**三个点**，然后**设置**）。
2. 在**节点与电源**下，查看**电池优化豁免**。如果显示**未设置**，点按**调整电池设置**，并允许 Parlons 不受限制地运行。
3. 确保已允许通知（[第 17 节](#17-notifications)）。
4. 打开**网络**标签页。确认**已连接主机**为 1 或更多。
5. 如果为 0，点按**自动连接**。

#### 如何恢复在线

1. 打开**网络**标签页。
2. 点按（或点击）**自动连接**，等待其完成。
3. 如果仍然离线，请检查您的手机或电脑是否能上网。
4. 在 Android 上，点按**管理**，确保**使用内置中继**已开启。在桌面版上，确认内置中继开关显示“内置中继：开启”。
5. 如果您知道某个可用的中继，请添加它（[第 19.2 节](#192-relays-hosts)）。
6. 查看该标签页底部的**事件日志**，了解原因。

#### 如何解决相机或麦克风不可用（Android）

1. 打开 Android 的**设置**应用。
2. 进入**应用**，然后**Parlons!**，然后**权限**。（名称因手机厂商而略有不同。）
3. 允许**相机**和**麦克风**。
4. 回到 Parlons 再试一次。

### 消息和联系人

| 症状 | 解决方法 |
|---|---|
| 显示“介绍已发送”，但联系人一直没有出现 | 对方的设备已关机或无法连接。设备恢复后，握手就会完成。如果一直没有完成，请让对方来添加您。 |
| “不是 Parlons 地址” / “这似乎不是 Parlons 地址” | 地址必须以 `Mx` 或 `MAX#` 开头。请重新完整复制。 |
| 消息延迟到达，或者只有打开应用时才到达（Android） | **设置**、**节点与电源**、**调整电池设置**。确认**网络**标签页显示至少有一个主机已连接。允许通知。 |
| 一个勾号一直没有变成两个 | 对方的设备还没有确认收到。设备已关机，或者对方的应用在后台被结束了。消息会等待，不会丢失。 |
| 我的消息上有一个红叉 | 没有中继愿意接收。消息留在您的发件箱中，并会重试。请检查您的网络连接和网络标签页。 |
| 状态标签显示“离线” | 没有中继在为您保持连接。应用会自动重新连接。如果一直如此，请打开网络标签页，确认**使用内置中继**已开启，或添加一个您知道的中继。 |
| “无法解析出可分享的 IP 地址” | 您处于离线状态。重新连接后，再次打开**分享我的地址**。 |
| 没有显示地址：“尚无地址，正在等待主机” | 应用仍在连接中。请等几秒钟。 |
| 使用经典 Maxima 的联系人收不到我的语音消息或电话 | 语音消息和通话需要双方都使用 Parlons。请改为发送文字。 |
| 我不想让某人再给我发消息 | 移除联系人只会把对方从您的列表中删除。对方仍然可以给您发消息。 |

### 媒体和文件

| 症状 | 解决方法 |
|---|---|
| “文件过大：单条消息最多可携带 16 MB” | 改为作为**私密文件**发送（最大 512 MB）。 |
| “照片不可用 · 点按重试” | 点按它。发送者的设备或中继可能离线；请稍后再试。 |

| 私密文件一直停在“等待其他节点” | 拥有该文件的人必须在线且可以被连接。请发送者打开 Parlons。如果聊天中没有任何人可以被直接连接，也没有人与您在同一局域网中，传输就无法开始。 |
| “准备过程已中断” | 移除该传输，然后重新选择文件。 |
| “请选择不超过 512 MB 的文件” | 文件太大，无法作为私密文件发送。 |
| 相机或“扫描对方二维码”没有反应 | 在提示时允许使用相机。第一次扫描时会请求此权限。 |
| “录音失败” / “麦克风不可用” | 在 Android 设置中允许 Parlons 使用麦克风。 |

| 桌面版显示来电，但我无法接听 | Parlons Desktop 不传输通话音频或视频。请在手机上接听。 |

### 报告问题

1. 记下您的平台和应用版本。打开**设置**，滚动到**关于**。
2. 写下您预期会发生什么，以及实际发生了什么。
3. 打开**网络**标签页，复制相关的**事件日志**内容。

日志中从不包含您的消息或您的助记词。但粘贴前仍请检查一遍，并且永远不要把助记词粘贴到任何地方。

## 24. 术语表

| 术语 | 含义 |
|---|---|
| **Parlons!** | 私密聊天应用。有 Android、桌面和 iPhone 版本。 |
| **Maxima** | Parlons 底层的消息传输层。它与经典 Minima Maxima 在协议层面完全兼容。 |
| **Minima** | 您钱包背后的区块链，也是其原生币的名称。 |
| **MxUSD** | 与美元挂钩的 Minima 代币。代币 ID 为 `0x7D39745FBD29049BE29850B55A18BF550E4D442F930F86266E34193D89042A90`。 |
| **身份** | 由您的 24 个词派生出的密钥对。它就是您在 Parlons 上的身份。 |
| **助记词 / 24 个词** | 用于生成您的身份和钱包的词。任何掌握它们的人都可以冒充您。 |
| **自定义短语（anyphrase）** | 非标准的 Minima 短语，完全按输入原样使用，包括大写字母和空格。 |
| **地址** | 别人联系您的方式。`Mx<key>@<host>:<port>` 会随中继变化；`MAX#<key>#<location service>` 是永久的。 |
| **公钥** | 地址中的 `Mx` 部分，以及设置中完整的“maxima publickey”。可以放心分享。 |
| **中继 / 主机** | 为您保持连接并传送封装流量的公共 Maxima 节点。它无法读取您的消息。 |
| **多重连接** | 同时连接多个中继，这样其中一个断开时，您也不会失去连接。 |
| **位置服务（MLS）** | 一个目录服务，回答“这个身份当前的地址是什么？”固定一个位置服务，您就可以获得永久 `MAX#` 地址。 |
| **介绍** | 添加联系人的握手过程。对方的设备回复后，对方就会出现。 |
| **邮箱** | 为离线用户保存的封装消息，对方回来后交付给对方。 |
| **发件箱** | 您自己等待中继接收的消息。 |
| **勾号** | 消息状态：正在发送、已发送（中继已接收）、已送达（对方设备已收到）、已读。 |
| **已读回执** | 可选功能。让联系人知道您何时读了他们的消息。默认关闭。 |
| **群组** | 包括您在内最多 12 人的聊天。每条消息都为每位成员单独加密。 |
| **管理员** | 可以更改成员的群组成员。 |
| **私密文件** | 最大 512 MB 的加密文件，直接在聊天成员之间共享。 |
| **可直接连接** | 您的设备拥有一个经过外部验证的真实公网地址，联系人无需中继即可联系到您。 |
| **运营商级 NAT（CGNAT）** | 网络服务商让许多客户共用一个公网地址。任何端口转发都无法打通。 |
| **协助网络** | Android 上的一个开关，让您的手机代存邮件、回答查询，并在连接 Wi-Fi 充电时充当中继。 |
| **签名使用次数 / 密钥使用次数** | Minima 钱包使用一次性密钥签名。计数器确保密钥绝不会被重复使用。它只增不减。 |
| **`.pbk` 备份** | 由您的密码保护的加密 Parlons 备份文件。 |
| **Parlons 账户** | 一个始终运行、保存您身份的程序，让多台设备可以共用这个身份。 |
| **Parlons Cloud** | 与 Parlons 账户配对的应用（Android 或 iPhone）。它本身不保存身份。 |
| **邀请 / 配对码** | 一个包含账户地址和一次性配对码的二维码或 `MAX#` 文本，用于配对设备。 |
| **托管账户** | 由别人在其机器上为您运行的 Parlons 账户。 |
| **Parlons Node** | 一个服务器软件包：集完整的 Minima 节点、中继和 Parlons 账户于一体。 |
| **经典引擎** | 通过经典 Maxima 进行路由的选项。大多数人应保持关闭。 |
| **核心节点** | 用于始终在线设备的标签。它只改变联系人看到的内容。 |
| **KeetChat** | 来自已连接的 minimaCore Desktop 节点的联系人。需要该节点在同一台电脑上运行。 |
| **minimaDocs** | 一个独立的文档应用，可以在设置中连接到您的 Parlons 账户。 |
