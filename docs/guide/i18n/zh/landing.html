开始使用

选一种方式，按步骤操作。

每种只要几分钟。你的 24 个词就是你的身份：把它们写在纸上，妥善保管。

在 Android 手机上聊天

需要 Android 9 或更高版本。

  1. 在手机上下载应用：
    parlons-{{ANDROID_VERSION}}.apk
  2. 打开下载的文件，点 安装。如果 Android 询问，请允许从浏览器安装应用。
  3. 打开 Parlons，点 创建新身份。
  4. 按顺序把 24 个词写在纸上。然后点 我已保存。
  5. 允许通知，这样有新消息时你就能看到。
查看详细说明 →

在电脑上聊天

Mac（Apple 芯片）、Windows 10/11 或 Linux。

  1. 下载 Parlons Desktop：
    MacWindowsLinux
  2. 安装。在 Mac 上，把 MaximaNode 拖进“应用程序”文件夹。在 Windows 上，如果出现蓝色提示框，点 更多信息，再点 仍要运行。
  3. 打开 MaximaNode。
  4. 把它显示的 24 个词抄下来。
查看详细说明 →

一个账户，所有设备通用

每部手机和每台电脑上都是同样的聊天。需要一台一直开着的 Linux 机器：一台服务器或一台 Raspberry Pi。

  1. 在 Linux 机器上粘贴：
    curl -fsSL {{NODE_INSTALL_SH}} | bash
  2. 提示时，设置一个管理员密码。再次提示时再输入一遍，屏幕上就会出现一个二维码。
  3. 在 Android 手机上安装 Parlons Cloud：
    parlons-cloud-portal-{{PORTAL_VERSION}}-release.apk
  4. 在 Parlons Cloud 里点 扫描配对二维码，扫描那个二维码，然后点 连接并配对。
查看详细说明 →

然后添加好友：打开 联系人，点 + 添加（在电脑上点 添加联系人），扫描或粘贴对方的地址，再点 发送介绍。对方设备回应后，对方就会出现在列表里。
