开始之前

几个常见问题。

可以和使用其他版本的人聊天吗？

可以。Parlons 应用使用同一消息网络，即使应用不同，也可以交换联系人地址聊天。

Cloud 是必须在这里购买的订阅吗？

Cloud 应用连接您安排好的账户。您可以运行自己的主机，或从托管者获取邀请。下载应用不会在本网站自动创建托管账户。

联系人二维码和配对邀请一样吗？

不一样。联系人地址让别人给您发消息；配对邀请让设备访问账户。请对配对邀请保密。

能用 24 个词同步两个应用吗？

共享账户请使用配对。在多个设备独立运行相同种子不会同步聊天历史。指南说明了备份和身份迁移。

为什么版本号不同？

手机应用、桌面应用和服务器分别发布版本。应按用途和设备选择，而非版本号大小。
