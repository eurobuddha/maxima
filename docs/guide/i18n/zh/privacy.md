# 隐私

2026 年 10 月 24 日起生效。适用于所有 Parlons 应用和程序：Android 应用、Android 版 Parlons Cloud、Parlons Desktop、Parlons 账户程序以及各个中继。

## 作者收集什么 {#what-the-authors-collect}

什么都不收集。没有数据分析，没有崩溃报告服务，没有广告标识符，没有跟踪，没有第三方 SDK，也不需要在作者那里注册账户。

## 什么留在你的设备上 {#what-stays-on-your-device}

Android 应用和电脑版把你的身份（24 个词）、联系人和聊天记录保存在设备上，只有你能读取。手机上的 Parlons Cloud 只保存一个设备密钥，以及你看过的内容的缓存；其余的都保存在账户里。

## Parlons 账户保存什么 {#what-a-parlons-account-holds}

账户把你的身份、联系人、聊天记录和已配对的设备保存在它运行的那台机器上。如果那台机器是你的，你的数据就在那里。如果是别人替你托管账户，那个人负责管理那台机器，拥有管理员拥有的访问权限；助记词在存储时用他们的密码加密。你随时可以带着加密备份离开，并保留你的地址。

## 什么会在网络上传送 {#what-travels}

消息使用接收方密钥进行端到端加密，并由发送方签名。中继传递加密内容，无法阅读。配对设备与 Cloud 账户之间也使用加密通道。对于 Cloud，账户主机是通信端点，保存账户密钥和可读历史。

## 加密隐藏什么，不隐藏什么 {#privacy-boundaries}

Parlons 不为分析统计或广告跟踪您的活动。这不等于保证任何人都看不到任何信息。

- 中继可观察路由密钥、连接信息和流量时间，但无法阅读消息内容。
- 直接通话和私密文件传输可能向其他参与者显示您的 IP 地址。
- 已解锁的设备或 Cloud 主机管理员可访问存储的数据。
- 支付记录在公开 Minima 区块链上，聊天加密不会隐藏交易记录。

[安全与隐私指南](parlons.html#22-security-and-privacy)解释了这些边界。

## 儿童 {#children}

这些应用本身不提供任何内容，也不需要注册；可能会和陌生人聊天。
