Застосунок для iPhone **ще недоступний**. Android потребує версії 9 або новішої. Завантаження для комп’ютерів призначені для Mac з Apple silicon, Windows 10/11 і Debian/Ubuntu x86-64.

## Parlons! на Android {#chat-on-your-android-phone}

**Оберіть, якщо:** хочете встановити один застосунок і спілкуватися без окремого сервера. Особа, контакти й листування зберігаються на телефоні. Застосунок з’єднується через мережу ретрансляторів Parlons.

### Встановлення та створення особи

1. Завантажте [Parlons! {{ANDROID_VERSION}} для Android]({{ANDROID_APK}}) на телефон.
2. Відкрийте APK і натисніть **Install (Встановити)**. Якщо потрібно, дозвольте браузеру встановлювати застосунки.
3. Відкрийте **Parlons!**, оберіть мову та натисніть **Create new identity (Створити нову особу)**.
4. Запишіть усі 24 слова на папері по порядку. Перевірте й натисніть **I've saved them (Я їх зберіг)**. Тримайте слова в таємниці: вони керують особою та можуть керувати гаманцем.
5. Дозвольте сповіщення. У **меню з трьома крапками → Settings (Налаштування)** введіть **Your name (Ваше ім’я)** і натисніть **Set (Встановити)**.
6. Перевірте **Network (Мережа)**: **Connected (Підключено)** означає з’єднання хоча б з одним ретранслятором. Можна додавати контакт.

**Особа вже є?** Перед відновленням прочитайте [посібник із копіювання та перенесення](parlons.html#20-backups-and-moving-to-a-new-device). Нова особа матиме іншу адресу. Відновлення однієї фрази на кількох увімкнених пристроях не синхронізує чати.

**Щоб залишатися на зв’язку:** дозвольте фонову роботу в налаштуваннях батареї Android. Оновлюйте встановленням нового APK поверх застосунку; перед видаленням або очищенням даних зробіть копію.

## Parlons Desktop {#chat-on-your-computer}

**Оберіть, якщо:** хочете спілкуватися з комп’ютера. Це окрема особа на ньому. Встановлення на телефон і комп’ютер не об’єднує їхні чати автоматично.

### Встановлення на комп’ютер

1. Завантажте відповідний інсталятор:
   - **Mac з Apple silicon:** [MaximaNode-{{DESKTOP_VERSION}}-notarized.dmg]({{DESKTOP_DMG}}). Відкрийте образ і перетягніть **MaximaNode** до Applications.
   - **Windows 10/11:** [MaximaNode-{{DESKTOP_VERSION}}.msi]({{DESKTOP_MSI}}). Відкрийте та дотримуйтеся вказівок.
   - **Debian/Ubuntu x86-64:** [maximanode_{{DESKTOP_VERSION}}_amd64.deb]({{DESKTOP_DEB}}). У папці завантаження виконайте `sudo apt install ./maximanode_{{DESKTOP_VERSION}}_amd64.deb`.
2. Відкрийте **MaximaNode** — так називається встановлений Parlons Desktop.
3. У вікні **Back up your Maxima seed** запишіть 24 слова по порядку й тримайте їх у таємниці.
4. Відкрийте **меню з трьома крапками**, введіть **Your name** і натисніть **Set**.
5. Перевірте з’єднання у **Network** та додайте контакт за інструкцією нижче. На комп’ютері вставляйте адресу: сканера QR через камеру немає.

**Дзвінки:** Desktop підтримує повідомлення й файли, але не передає звук або відео дзвінків. Для них використовуйте Android. Залишайте Desktop запущеним; щоб вийти, оберіть **Quit** біля значка в треї.

Проблеми встановлення й перенесення особи описані в [посібнику Parlons!](parlons.html).

## Parlons Cloud: підключення за запрошенням {#pair-an-account}

**Оберіть, якщо:** уже маєте запрошення або обліковий запис на власній машині. Android-застосунок — віддалений інтерфейс: особа й історія знаходяться на хості. Кілька під’єднаних телефонів бачать один обліковий запис.

**Перед початком:** отримайте запрошення від власника хоста або під’єднаного пристрою. Якщо хоста немає, спочатку [запустіть власний обліковий запис](start-node.html). QR контакту дозволяє спілкуватися з людиною; запрошення на сполучення дає доступ до облікового запису. Це різні речі.

### Встановлення та сполучення

1. Завантажте [Parlons Cloud {{PORTAL_VERSION}} для Android]({{PORTAL_APK}}). Відкрийте APK, за потреби дозвольте встановлення та натисніть **Install**.
2. Відкрийте **Parlons Cloud**. Натисніть **Scan pairing QR (Сканувати QR сполучення)** або вставте повне запрошення в **Account address or pairing invite (Адреса або запрошення)**.
3. Натисніть **Connect & pair (Підключити й сполучити)**. Спочатку з’явиться підключення до мережі, потім пошук і сполучення, далі відкриється обліковий запис.
4. Дозвольте сповіщення. У **More → Settings → This device (Ще → Налаштування → Цей пристрій)** оберіть **Keep running in the background (Працювати у фоні)**, якщо пункт доступний.
5. Відкрийте **Node (Вузол)**, перевірте з’єднання та список пристроїв. Далі почніть розмову за інструкцією нижче.

**Код не підходить?** Можливо, його використано або замінено. Попросіть нове запрошення. Код працює один раз; до використання тримайте його в таємниці. Для листування діліться адресою контакту.

**Ще один телефон:** на під’єднаному телефоні відкрийте **Node → Pair my other device (Під’єднати інший пристрій)**. Якщо потрібно, введіть пароль адміністратора й відскануйте нове запрошення іншим телефоном. Втрачений телефон від’єднайте через **Node → Paired devices → Revoke (Пристрої → Відкликати)**.

**Чужий хост:** оператор може читати ключі й історію на своїй машині. Обирайте людину, якій довіряєте. Вбудовані гостьові облікові записи пропонують чат, дзвінки й файли без гаманця та керування вузлом. Інші типи розміщення можуть відрізнятися. Див. [посібник Cloud](cloud.html).

## Альтернатива: легкий хостинг облікового запису {#one-account-on-all-your-devices}

**Оберіть, якщо:** хочете, щоб обліковий запис працював із вимкненим телефоном, та хочете під’єднати кілька телефонів. **Сервер Parlons Cloud** легший за повний вузол: обслуговує обліковий запис без повного блокчейну Minima. Android-застосунок Cloud підключається до нього.

**Потрібні:** Mac, Linux, Raspberry Pi або Windows PC, що залишається ввімкненим, не спить і має інтернет. На Mac заздалегідь встановіть Java 11+ або Homebrew; Linux може потребувати sudo для залежностей. Домен не потрібний. Інсталятор створює обліковий запис; для наявної особи спочатку прочитайте [перенесення](cloud.html#move-an-account-to-another-machine).

### Встановлення на хост

1. На **Mac або Linux** відкрийте термінал на постійно ввімкненій машині:

   ```
   curl -fsSL {{INSTALL_SH}} | bash
   ```

   На **Windows 10/11** відкрийте PowerShell:

   ```
   irm {{INSTALL_PS1}} | iex
   ```

   Автори ще не перевіряли інсталятор на Windows. Для перевіреного серверного варіанта оберіть підтримуваний Linux.
2. Дочекайтеся встановлення залежностей, завантаження випуску й запуску. Збережіть запрошення в таємниці. Mac/Linux може показати QR, Windows — текст для вставлення.
3. На Android виконайте [встановлення та сполучення Cloud](start-pair.html).
4. У новому терміналі хоста виконайте `parlons status`. `parlons panel` відкриває локальну вебпанель; `parlons newcode` створює запрошення.
5. На телефоні у **More → Settings → Show seed phrase (Показати фразу)** запишіть слова приватно, потім через **Back up account… (Резервна копія…)** збережіть зашифровану копію.

**Не присипляйте хост.** На Mac і Windows служба запускається при вході користувача. Сплячий або відключений хост не обслуговує обліковий запис. Інсталятор також вмикає ретранслятор на TCP 9501. Обліковий запис працює через вихідні з’єднання; публічному ретранслятору потрібний доступний ззовні порт. [Параметри хостингу й ретранслятора](cloud.html#19-one-account-on-your-own-machine-the-one-line-installers).

**Обслуговування:** `parlons log` показує журнал; на Mac/Linux `parlons update` оновлює сервер, на Windows запустіть інсталятор знову. Перед оновленням зробіть копію. Для окремої особи друга використовуйте **Node → Manage hosted accounts (Керування розміщеними обліковими записами)**, а не запрошення до свого. [Розміщення друзів](cloud.html#11-hosting-friends-guest-invitations).

## Запустіть свій вузол Parlons Cloud {#run-a-full-node}

**Запустіть Parlons Cloud, щоб надати мережі найповнішу підтримку.** Ваша постійно ввімкнена машина запускає **повний вузол Minima й повноцінний ретранслятор**, надає один обліковий запис кільком сполученим пристроям і дозволяє запрошувати друзів до **окремих облікових записів-орендарів**. Кожен друг має власну особу, контакти й розмови.

Програма для повного варіанта Cloud називається **Parlons Node**. Застосунок **Parlons Cloud** для Android підключає до неї телефон. Майбутній застосунок iPhone працюватиме так само; поки він недоступний.

**Потрібні:** постійно ввімкнений Linux із systemd та sudo/root; підійде 64-бітна Raspberry Pi. Плануйте пам’ять і зростання ланцюга за [вимогами](node.html#3-requirements): посібник радить 2 ГБ RAM для звичайного вузла, 8 ГБ для MegaMMR. Інсталятор може ввімкнути MegaMMR на менших машинах, тому оберіть режим явно.

### Встановлення, сполучення та перевірка

1. Для **звичайного повного вузла без MegaMMR** виконайте на сервері:

   ```
   curl -fsSL {{NODE_INSTALL_SH}} | bash -s -- --no-megammr
   ```

   Для шлюзу гаманця з MegaMMR налаштуйте пам’ять за [повним посібником встановлення](node.html#5-three-ways-to-install).
2. Інсталятор за потреби додає Java, запускає системну службу й відкриває TCP 9001 та 9501 у підтримуваному активному брандмауері. Перевірте також брандмауер провайдера або роутер. Синхронізація ланцюга може тривати довше за запуск облікового запису.
3. Задайте **пароль адміністратора для сполучення**, потім введіть його для показу QR. Пізніше запрошення можна отримати командою `sudo parlons-pair --admin`.
4. На Android виконайте [сполучення Cloud](start-pair.html), відскануйте запрошення й натисніть **Connect & pair**.
5. Перевірте `systemctl is-active parlons-node`. Останні записи: `sudo journalctl -u parlons-node -n 50 --no-pager`.
6. Виконайте [резервне копіювання фраз та особи](node.html#20-seeds-identity-and-backups). Фрази чату й гаманця вузла можуть відрізнятися; за потреби збережіть обидві.

Керуйте обліковим записом і пристроями на вкладці **Node**. Інструменти вузла є у власника, але не в гостя. Оновлення, спостереження та відновлення — у [посібнику Node](node.html).

### Ваш обліковий запис на інших пристроях

1. На під’єднаному телефоні відкрийте **Node → Pair my other device**.
2. За запитом введіть **пароль адміністратора**. Покажіть новий QR або скопіюйте запрошення.
3. На іншому Android встановіть **Parlons Cloud**, скануйте чи вставте запрошення та натисніть **Connect & pair**. Відкриється той самий обліковий запис із контактами й чатами. Для кожного пристрою створюйте нове запрошення.

Сполучення відкриває наявний обліковий запис, а не незалежну копію особи. Для комп’ютера є [сполучений клієнт командного рядка](cloud.html#how-to-drive-an-account-from-another-machine). Встановлення самостійного Parlons Desktop не підключає його автоматично.

### Запрошуйте друзів до окремих облікових записів

**Орендар (tenant)** — окремий обліковий запис на вашому вузлі Cloud. Другові не потрібний власний сервер: він матиме власну особу й листування.

1. На під’єднаному телефоні відкрийте **Node → Manage hosted accounts**.
2. Уперше оберіть **Hosting options → Enable hosting**. Пароль адміністратора має бути заданий. Залишайте вузол увімкненим, щоб друзі залишалися онлайн.
3. Натисніть **Create account**, введіть назву облікового запису друга й натисніть **Create**.
4. Натискайте **Refresh** до стану **running**. Оберіть обліковий запис і **Show invitation**.
5. Передайте запрошення другові приватно. Він встановить **Parlons Cloud**, відсканує чи вставить запрошення й натисне **Connect & pair**.
6. Для іншого друга створіть ще один обліковий запис. **Pair my other device** використовуйте для додавання власних пристроїв.

Вбудований хост підтримує до десяти чат-облікових записів: повідомлення, дзвінки й файли без вашого гаманця та керування вузлом. Окрема служба tenants підтримує й повні облікові записи з власними гаманцями: [варіанти хостингу](cloud.html#21-many-accounts-the-parlons-tenants-service). Ви зберігаєте дані та ключі гостей, тому запрошуйте тих, хто вам довіряє, і допомагайте їм робити копії.

### Підтримуйте мережу й готуйтеся до iPhone

Залишайте вузол онлайн, а повноцінний ретранслятор — доступним ззовні, щоб він передавав повідомлення інших людей. Після налаштування брандмауера чи роутера перевірте [зовнішню доступність](node.html#23-verifying-from-outside).

**Parlons Cloud стане способом користуватися Parlons! на iPhone.** Застосунок підключиться до вашого вузла Cloud або окремого облікового запису на вузлі друга. Застосунок поки недоступний, але облікові записи й хостинг уже працюють.

## Перша розмова {#add-a-friend}

1. Попросіть **адресу або QR контакту**, а не запрошення на сполучення.
2. Відкрийте **Contacts → + Add (Контакти → Додати)**; на комп’ютері — **Add contact**.
3. На Android скануйте QR або вставте повну адресу; на комп’ютері вставте її. Натисніть **Introduce myself (Представитися)**.
4. Дочекайтеся відповіді пристрою на представлення. Якщо він відключений, контакт може з’явитися не одразу.
5. Відкрийте чат, введіть повідомлення, натисніть стрілку надсилання й попросіть відповісти.

Свою адресу можна передати з **Contacts**. Передавайте її повністю. Різні версії Parlons можуть обмінюватися повідомленнями.

## Щоденне користування {#everyday-use}

- **Повідомлення:** відкрийте розмову в **Chats**. Черга означає очікування; одна галочка — повідомлення в ретранслятора; дві — підтвердження пристрою одержувача. Позначка прочитання залежить від увімкнених сповіщень про прочитання.
- **Фото й файли:** натисніть **Attach (Додати вкладення)**. На Android оберіть **Photo library (Галерея)** або **Private file (Приватний файл)** та надішліть. Параметри Desktop — у [посібнику застосунку](parlons.html).
- **Дзвінки:** в особистому чаті Android натисніть **Voice call** або **Video call**, дозвольте мікрофон і камеру. Desktop не передає звук і відео дзвінка.
- **Групи:** на Android **Chats → New group**, введіть назву, оберіть контакти й натисніть **Create**.
- **Сповіщення:** дозвольте їх і фонову роботу в Android. Для Cloud хост також має бути онлайн.
- **Платежі:** в особистому чаті облікового запису з гаманцем оберіть **Attach → Send payment**, Minima або MxUSD та введіть суму. Перед підтвердженням перевірте одержувача й суму. Платежі проходять у публічному блокчейні Minima; шифрування чату не робить їх анонімними. Чат-облікові записи гостей не мають платежів. [Інструкція](parlons.html#15-payments-minima-and-mxusd).

## Зробіть копію заздалегідь {#backups}

**24 слова відновлюють особу, а не старе листування.** Запишіть їх на папері та тримайте в таємниці. Нікому не надсилайте й не вводьте на сайтах. Збережіть і окрему фразу гаманця, якщо вона є.

- **Parlons! Android:** **Settings → Keys & security → Back up identity…** створює зашифрований `.pbk`: особа, контакти й налаштування без історії чатів.
- **Parlons Cloud:** **More → Settings → Keys & backup → Back up account…** створює зашифрований `.pbk` з контактами та історією, без вмісту медіа й приватних файлів.
- **Desktop:** збережіть фразу; перед зміною комп’ютера прочитайте [копіювання та перенесення](parlons.html#20-backups-and-moving-to-a-new-device).

Зберігайте копію поза початковим пристроєм і збережіть пароль: відновити його за вас неможливо. Для одного облікового запису на кількох телефонах використовуйте сполучення, а не незалежні копії одного seed.

## Якщо щось не працює {#need-more}

| Проблема | Що спробувати |
|---|---|
| Cloud не сполучається | Перевірте хост, повний текст запрошення та свіжий одноразовий код. |
| Представлення очікує | Попросіть співрозмовника відкрити застосунок і перевірити з’єднання. |
| Повідомлення лише з відкритим застосунком | Дозвольте сповіщення й фон; для Cloud перевірте хост. |
| Залишається одна галочка | Ретранслятор отримав повідомлення, пристрій адресата ще не підтвердив; перевірте його з’єднання. |
| Втрачено під’єднаний телефон | Відкличте його на вкладці Node іншого під’єднаного телефона. |

Докладніше: [Parlons!](parlons.html), [Cloud](cloud.html), [Node](node.html). У [повідомленні про помилку]({{ISSUES}}) вкажіть застосунок, версію, пристрій і точний текст помилки. Не додавайте фрази, паролі чи невикористані запрошення.
