Переписка на телефоне Android

Android 9 или новее.

  1. Скачайте приложение на телефон:
    parlons-{{ANDROID_VERSION}}.apk
  2. Откройте скачанный файл и нажмите Установить. Если Android спросит, разрешите установку из браузера.
  3. Откройте Parlons и нажмите Создать новую личность.
  4. Запишите 24 слова на бумаге по порядку. Нажмите Я сохранил(а) слова.
  5. Разрешите уведомления, чтобы видеть новые сообщения.

Переписка на компьютере

Mac (Apple silicon), Windows 10/11 или Linux.

  1. Скачайте Parlons Desktop:
    MacWindowsLinux
  2. Установите его. На Mac перетащите MaximaNode в папку «Программы». В Windows, если появится синее окно, нажмите Подробнее, а затем Выполнить в любом случае.
  3. Откройте MaximaNode.
  4. Запишите 24 слова, которые появятся на экране.

Один аккаунт на всех ваших устройствах

Одни и те же чаты на каждом телефоне и компьютере. Нужен компьютер с Linux, который всегда включён: сервер или Raspberry Pi.

  1. На компьютере с Linux вставьте:
    curl -fsSL {{NODE_INSTALL_SH}} | bash
  2. Когда попросят, придумайте пароль администратора. Введите его ещё раз, когда попросят, и появится QR-код.
  3. Установите Parlons Cloud на телефон Android:
    parlons-cloud-portal-{{PORTAL_VERSION}}-release.apk
  4. В Parlons Cloud нажмите Сканировать QR-код подключения, отсканируйте код и нажмите Подключить устройство.
Подробнее →

Затем добавьте друга: откройте Контакты, нажмите + Добавить (на компьютере — Добавить контакт), отсканируйте или вставьте его адрес и нажмите Представиться. Друг появится в списке, когда его устройство ответит.
