# Руководство пользователя Parlons!

Приватный чат без посредников.

В этом руководстве описаны:

- **Parlons! для Android**, версия **0.6.145**. Это полноценное приложение. Ваша личность хранится на телефоне.
- **Parlons Desktop**, версия **1.5.115**, для Mac, Windows и Linux. Это полноценное приложение для компьютера. Оно устанавливается под именем **MaximaNode**.
- Кратко — **Parlons Cloud** для Android (версия **0.2.90**) и iPhone. Эти приложения подключаются к постоянно работающему аккаунту Parlons. Портал подробно описан в [руководстве Parlons Cloud](parlons-cloud-portal.md), а работа собственного сервера аккаунтов — в [руководстве Parlons Node](parlons-node.md).

Все файлы для загрузки находятся на странице выпусков: <https://github.com/eurobuddha/maxima/releases>

Каждая задача в этом руководстве разбита на пронумерованные шаги. Надписи, выделенные **жирным**, — это точные слова, которые вы видите на экране. Там, где Android и Desktop различаются, для каждого приведены свои шаги.

## 1. Что такое Parlons

Parlons — это приватный чат, в котором между вами нет никакой компании.

- **Регистрации нет.** Ни номера телефона, ни электронной почты, ни аккаунта у какого-либо сервиса.
- Ваши сообщения **запечатываются на вашем устройстве**, прежде чем покинуть его. Открыть их может только тот, кому вы написали.
- Запечатанные сообщения передают **ретрансляторы**, которые запускают такие же люди, как вы. Ретрансляторы не могут их прочитать.
- Ваша личность — это **24 слова**. Эти же слова являются и **кошельком Minima**. Тот, у кого есть эти слова, — это вы.

Что можно делать:

- Личные чаты и группы до 12 человек.
- Фото, голосовые сообщения и обмен контактами.
- Приватные файлы до 512 МБ, которые передаются в зашифрованном виде напрямую между участниками чата.
- Голосовые и видеозвонки (Android).
- Отправлять Minima или **MxUSD**, долларовый токен Minima, прямо в чате.
- Пользоваться приложением на английском, упрощённом китайском, русском или украинском языке.

Parlons — проект с открытым исходным кодом, который поддерживает сообщество. Службы поддержки нет, потому что нет аккаунта в компании, который можно было бы проверить. Поддержка — это данное руководство, пояснения «Что это?» в приложении и трекер задач.

## 2. Как это работает

Чтобы пользоваться Parlons, это знать не обязательно. Но это помогает, когда что-то идёт не так.

### У вашего устройства нет постоянного адреса, поэтому оно его заимствует

Телефон в сети Wi-Fi или мобильной сети обычно не может принимать входящие подключения. Поэтому Parlons сам **подключается** к нескольким ретрансляторам (в приложении они также называются **узлами**). Каждый ретранслятор держит это подключение открытым. Всё, что адресовано вам, приходит обратно по нему.

- **Подключено** означает, что хотя бы один ретранслятор держит для вас подключение.
- **Нет подключения** означает, что сейчас с вами никто не может связаться. Писать при этом можно. Сообщения уйдут, когда ретранслятор снова будет доступен.

Parlons подключается **сразу к нескольким ретрансляторам**. Если один выйдет из строя, остальные продолжат вас обслуживать.

### Сообщения запечатаны сквозным шифрованием

Каждое сообщение шифруется на устройстве отправителя ключом получателя и подписывается отправителем. Ретранслятор видит запечатанный блок данных и ключ маршрутизации. Он может понять, что кто-то отправляет что-то на определённый ключ. Но что именно — не узнает никогда.

### Сообщения для тех, кто не в сети, дожидаются их

Если человек, которому вы пишете, не в сети, запечатанное сообщение хранится в **почтовом ящике**, пока он не вернётся. Кроме того, приложение хранит ваши ещё не отправленные сообщения в **папке исходящих** и повторяет попытки.

### Галочки говорят правду

| Значок | Значение |
|---|---|
| ⋯ («Отправка…») | В очереди. Ещё не передано ретранслятору. |
| ✓ одна серая галочка («Отправлено», ретранслятор принял) | Ретранслятор принял сообщение. |
| ✓✓ две серые галочки («Доставлено») | Собственное устройство собеседника подтвердило, что сообщение у него. В группе — оно есть у каждого текущего участника. |
| ✓✓ две синие галочки («Прочитано») | Собеседник прочитал сообщение. Показывается, только если он включил отчёты о прочтении. |
| ✗ («Не удалось отправить») | Ни один ретранслятор не принял сообщение. Оно остаётся в папке исходящих, и попытки повторяются. |

Две галочки ставит само устройство получателя, а не ретранслятор. Поэтому им можно доверять.

## 3. Какое приложение мне нужно?

Ответьте на один вопрос: вы хотите общаться на **этом устройстве** или иметь **один аккаунт на всех устройствах**?

| Что вам нужно | Что использовать | Примечания |
|---|---|---|
| Общаться на телефоне Android | **Parlons!** (приложение для Android) | Ваша личность хранится на телефоне. Android 9 или новее. |
| Общаться на компьютере | **Parlons Desktop** | Mac, Windows, Linux. Ваша личность хранится на компьютере. Java уже входит в комплект. |
| Одни и те же чаты на телефоне и ноутбуке или на iPhone | **Аккаунт Parlons** и **Parlons Cloud** на каждом устройстве | Аккаунт работает на постоянно включённом компьютере. См. [раздел 21](#21-one-account-on-every-device-parlons-cloud-your-own-account-hosted-accounts). |

> **Важно:** приложение для Android и Parlons Desktop хранят **каждое свою** личность. Если вы установите оба и создадите личность в каждом, у вас будет два разных адреса. Чтобы пользоваться одной личностью в двух местах, используйте аккаунт Parlons. Никогда не восстанавливайте одни и те же 24 слова на двух устройствах, которые работают одновременно.

### Что умеет каждое приложение

| Функция | Приложение для Android | Parlons Desktop |
|---|---|---|
| Чаты и группы | Да | Да |
| Фото | Да, в том числе с камеры | Да, в том числе вставка из буфера обмена |
| Голосовые сообщения | Да (до 60 секунд) | Да |
| Приватные файлы (до 512 МБ) | Да | Да |
| Голосовые и видеозвонки | Да | Нет. Входящие звонки отображаются и вежливо отклоняются. Отвечайте с телефона. |
| Отправка Minima или MxUSD | Да | Да |
| Вкладка «Кошелёк» | Да | Да |
| Сканирование QR-кода | Да | Камеры нет. Вместо этого вставляйте адреса. |
| Зашифрованный файл резервной копии личности | Да | Нет. Храните свои 24 слова. |
| Блокировка приложения (отпечаток пальца или PIN-код) | Да | Нет |
| Сочетания клавиш для размера текста | Нет | Да |

Parlons Cloud для Android тоже умеет совершать и принимать звонки и отправлять платежи от имени подключённого аккаунта. В Parlons для iPhone пока нет звонков и отправки платежей.

## 4. Установка

### 4.1 Android

Вам понадобится телефон с **Android 9 или новее**, а также ручка и бумага.

Parlons **нет в Play Маркете**. Приложение загружается напрямую и подписано его авторами.

1. Откройте на телефоне страницу выпусков: <https://github.com/eurobuddha/maxima/releases>
2. Найдите выпуск Parlons для Android **0.6.145** и нажмите на его файл `.apk`, чтобы скачать его.
3. Android спросит, разрешить ли установку из браузера. Разрешите для этой установки. Потом это можно снова отключить: «Настройки» → «Приложения» → «Специальный доступ» → «Установка неизвестных приложений».
4. Нажмите **«Установить»**, затем **«Открыть»**.

Если на вашем телефоне уже есть магазин PandaApps, Parlons! есть и там, и обновляется через него.

**Обновление.** Установите новый APK поверх старого. Ваша личность, контакты и чаты сохранятся.

### 4.2 Mac

1. Скачайте со страницы выпусков образ диска Parlons Desktop **1.5.115** (`.dmg`). Он подписан и заверен Apple, поэтому macOS открывает его без предупреждений.
2. Откройте образ диска. Перетащите **MaximaNode** в папку «Программы».
3. Откройте приложение из папки «Программы». Java уже входит в комплект. Больше ничего устанавливать не нужно.

Требуется Mac с процессором Apple (M1 или новее) и macOS 13 или новее. Образ диска собран только для arm64.

**Обновление.** Установите новый образ диска поверх старого приложения. Ваши данные в `~/.maxima` сохранятся.

### 4.3 Windows

1. Скачайте со страницы выпусков установщик Parlons Desktop **1.5.115** (`.msi`).
2. Запустите его. Windows может показать синее окно **«Система Windows защитила ваш компьютер»**, потому что установщик пока не подписан сертификатом Microsoft. Нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**.
3. Выберите папку. Папка по умолчанию подойдёт. Приложение устанавливается только для вашего пользователя, не требует прав администратора и добавляет Parlons в меню «Пуск». Java уже входит в комплект.

Требуется 64-разрядная Windows 10 или 11.

**Обновление.** Запустите новый установщик поверх старого. Ваши данные сохранятся.

### 4.4 Linux

Parlons Desktop — это 64-разрядный пакет x86 для Debian, Ubuntu и родственных дистрибутивов. Java уже входит в комплект.

1. Скачайте со страницы выпусков пакет Parlons Desktop **1.5.115** `.deb`.
2. В терминале, в папке, куда вы его сохранили, выполните:

   ```
   sudo apt install ./maximanode_1.5.115_amd64.deb
   ```

3. Откройте **MaximaNode** из меню приложений. Файл запуска — `/opt/maximanode/bin/MaximaNode`.

Сборки приложения для компьютера под ARM нет. На Raspberry Pi вместо этого запустите аккаунт Parlons ([раздел 21](#21-one-account-on-every-device-parlons-cloud-your-own-account-hosted-accounts)).

**Обновление.** Установите новый пакет поверх старого. Ваши данные в `~/.maxima` сохранятся.

### 4.5 iPhone

Приложение для iPhone — это **Parlons Cloud для iPhone**. Собственной личности в нём нет. Оно подключается к аккаунту Parlons. Apple не позволяет приложению оставаться доступным в фоне, поэтому только так iPhone может получать сообщения, пока приложение закрыто.

Приложение для iPhone **пока недоступно**: его нет в App Store, и тестовой сборки для загрузки тоже нет. Ему потребуется iOS 17 или новее. А пока пользуйтесь Parlons на Android или на компьютере. О том, как будет работать подключение, см. [раздел 21](#21-one-account-on-every-device-parlons-cloud-your-own-account-hosted-accounts).

## 5. Первый запуск: ваша личность

### 5.1 Android

1. **Выберите язык.** При первом открытии Parlons появляется окно **Language · 语言 · Язык · Мова**. Нажмите на свой язык. Позже его можно изменить.
2. На экране приветствия написано **Parlons!** и предлагается:
   - **Создать новую личность**
   - **Восстановить по сид-фразе**
   - **Изменить язык**

#### Создание новой личности

1. Нажмите **«Создать новую личность»**.
2. Появится окно **«Запишите эти 24 слова»**. Слова пронумерованы. На этом экране снимки экрана заблокированы.
3. Запишите все 24 слова на бумагу **по порядку**, вместе с номерами.
4. Сверьте каждое слово с экраном.
5. Нажимайте **«Я сохранил(а) слова»** только после этого.

Есть кнопка **«Копировать»**. Она помещает слова в буфер обмена и очищает его через 60 секунд. По возможности не пользуйтесь ею. Другие приложения могут читать буфер обмена, а менеджер буфера обмена может сохранить копию.

> Это **единственный** способ восстановить вашу личность и средства. Храните листок вне сети и никому его не показывайте. Тот, у кого есть эти слова, — это вы.

#### Восстановление уже существующей личности

Делайте это, только если на устройстве, где были эти слова, Parlons **больше не работает**. Одна личность должна находиться только в одном месте одновременно.

1. Нажмите **«Восстановить по сид-фразе»**.
2. Введите или вставьте фразу в поле **«Введите сид-фразу»**. На этом экране снимки экрана заблокированы.
3. Если ваша фраза получена в режиме Minima «anyphrase» (произвольная фраза, а не 24 стандартных слова), отметьте **«Произвольная фраза (Minima anyphrase)»**. Затем введите её **в точности**, сохранив все заглавные буквы и пробелы.
4. Нажмите **«Восстановить»**.
5. Появится сообщение **«Ваша личность восстановлена на этом телефоне.»** Нажмите **«Начать»**.

Также может появиться одно из этих примечаний:

- **«Примечание: контрольной суммы BIP39 нет — это нормально для фразы из узла Minima. Восстановление выполнено.»** Это нормально для фразы, полученной из узла Minima.
- **«Произвольная фраза восстановлена в точности как введена.»** Вы использовали режим произвольной фразы.

Окно восстановления также предупреждает об **использованиях ключей**. Ваш кошелёк подписывает одноразовыми ключами. Сами слова не содержат информации о том, сколько ключей уже использовано. Если этой фразой когда-либо подписывались транзакции в другом кошельке или на другом узле, не отправляйте средства из Parlons, пока не проверите это. Полная зашифрованная резервная копия ([раздел 20](#20-backups-and-moving-to-a-new-device)) содержит точное число.

> Сид-фраза возвращает только вашу **личность**. Старые чаты и контакты она не возвращает. Контакты по-прежнему смогут с вами связаться, потому что ваш адрес остаётся тем же.

#### После первого экрана

1. Android попросит разрешения на отправку уведомлений. **Разрешите.** Без этого вы не увидите входящие сообщения.
2. Откройте **«Настройки»**: нажмите **три точки** (справа вверху), затем **«Настройки»**. В разделе **«Узел и питание»** проверьте пункт **«Исключение из оптимизации батареи»**. Если там написано **«не настроено»**, нажмите **«Настроить батарею»** и разрешите Parlons работать без ограничений. Android закрывает фоновые приложения, а для чата это означает пропущенные сообщения, особенно ночью.
3. В **«Настройках»**, в разделе **«Ваше имя»**, введите имя, которое должны видеть ваши контакты, и нажмите **«Задать»**. Имя может содержать до 32 символов.

### 5.2 Parlons Desktop

1. Откройте **MaximaNode**.
2. Приложение создаст вашу личность и покажет окно **«Сохраните сид-фразу Maxima»** с сообщением «Ваш узел Maxima создал новую личность.» и вашими 24 словами.
3. Сразу запишите их по порядку.
4. Слова также сохраняются в файле, который может читать только ваша учётная запись пользователя:

   | Система | Файл с сид-фразой |
   |---|---|
   | Mac | `~/.maxima/seed.txt` |
   | Linux | `~/.maxima/seed.txt` |
   | Windows | `C:\Users\<you>\.maxima\seed.txt` |

5. Откроется вкладка **«Чаты»**.
6. Укажите своё имя. Нажмите кнопку с **тремя точками** (справа вверху). Откроются **«Настройки»**. В разделе **«Ваше имя»** введите имя в поле **«Отображаемое имя»** и нажмите **«Задать»**.

Окно резервного копирования появляется только при самом первом запуске. Если вы его пропустили, см. [раздел 18.2](#182-desktop-settings), чтобы снова показать слова.

## 6. Знакомство с приложением

### 6.1 Android

В верхней панели отображаются **Parlons!**, версия и значок состояния. Значок показывает, к скольким ретрансляторам (узлам) вы подключены, или **«не в сети»**.

Кнопки верхней панели:

| Кнопка | Что делает |
|---|---|
| Поиск (лупа) | Поиск по сообщениям, контактам и группам. |
| Тема | Переключает «Системная», «Светлая» и «Тёмная». Короткая подсказка показывает новый выбор, например «Тема: Тёмная». |
| Три точки | Меню: **«Новая группа»**, **«Сканировать QR-код»**, **«Поиск»**, **«Настройки»**. |

Под верхней панелью расположены четыре вкладки. Нажмите на вкладку или проведите пальцем в сторону:

| Вкладка | Что на ней |
|---|---|
| **Чаты** | Ваши разговоры, новые сверху. |
| **Контакты** | Ваша карточка с адресом, ваши контакты и **«+ Добавить»**. |

## 7. Ваш адрес

Ваш адрес — это то, по чему люди связываются с вами. Это публичный ключ, а не номер телефона.

### Две формы

| Форма | Как выглядит | Меняется ли? |
|---|---|---|
| **Текущий адрес** | `Mx<your key>@<host>:<port>` | Часть `Mx` не меняется никогда. Часть после `@` — это ретранслятор, который обслуживает вас прямо сейчас; она меняется при смене ретрансляторов. Ваши контакты узнают об этом автоматически. |
| **Постоянный адрес** | `MAX#<key>#<location service>` | Не меняется никогда, даже при переходе между ретрансляторами. Если он у вас есть, делитесь им. |

Оба адреса длинные. Они всегда показываются полностью, и копировать их всегда нужно полностью. Сокращённым адресом воспользоваться нельзя.

### Как показать адрес и поделиться им (Android)

1. Откройте вкладку **«Контакты»**. На карточке вверху написано **«Ваш адрес Parlons»**.
2. Нажмите **«Поделиться моим адресом»**.
3. Появится QR-код, а под ним ваш полный адрес. Нажмите на адрес, чтобы скопировать его.
4. Нажмите **«Поделиться…»**, чтобы отправить его через любое другое приложение, или дайте другу отсканировать QR-код.

Если у вас есть постоянный адрес, на панели написано: «Ваш ПОСТОЯННЫЙ адрес — он сохраняется при любой смене узла». В противном случае указано, через сколько ретрансляторов с вами можно связаться.

Если вы видите **«Не удалось определить IP-адрес для обмена.»**, проверьте подключение и откройте панель снова.

### Как показать адрес и поделиться им (Desktop)

1. Откройте вкладку **«Контакты»**. На карточке написано **«Ваш адрес Maxima»**.
2. Нажмите **«Поделиться моим адресом»**. Откроется окно с QR-кодом, который можно отсканировать телефоном.
3. Под QR-кодом каждый адрес показан полностью. При наличии постоянного адреса вы увидите **«Постоянный адрес MAX#»** и **«Текущий адрес»**. Без него — **«Адрес Maxima»**. Нажмите на адрес, чтобы скопировать его. Подсказка гласит **«Нажмите, чтобы скопировать»**.
4. Вставьте его в письмо или любое другое сообщение для этого человека.

Если вы видите «Не удалось определить адрес для отправки. Повторите попытку после подключения.», проверьте подключение и снова нажмите **«Поделиться моим адресом»**.

### Как получить постоянный адрес

Постоянный адрес `MAX#` выдаёт **служба расположения** (также называемая MLS). Она отвечает на один вопрос: «какой текущий адрес у этой личности?»

#### Как получить постоянный адрес (Android)

1. Откройте вкладку **«Сеть»**.
2. Найдите карточку **«Служба расположения · находит вас при смене сети»** и нажмите **«Настройки расположения»**.
3. Выберите один из вариантов:
   - **«Использовать пул eurobuddha (регистрация)»**. Появится сообщение «Регистрация завершена: у вас есть постоянный адрес MAX#».
   - **«Сделать этот адрес постоянным»** — чтобы закрепить службу расположения, которую предлагает ваш ретранслятор.
   - Укажите службу расположения сами (в формате `Mx<key>@<host>:<port>`) и нажмите **«Закрепить этот MLS»**.
   - **«Использовать каталог узла»** возвращает вариант по умолчанию.

#### Как получить постоянный адрес (Desktop)

1. Откройте вкладку **«Сеть»**.
2. Найдите карточку **«Служба расположения · находит вас при смене сети»**. На ней показаны **адрес службы расположения** и её **режим**: **«статический (закреплён)»** или **«меняющийся (назначен узлом)»**.
3. Нажмите **«Настройки расположения»**.
4. Выберите один из вариантов:
   - **«Использовать пул eurobuddha (регистрация)»**. Появится сообщение «Регистрация выполнена — постоянный адрес MAX# активен».
   - Укажите службу расположения в формате `Mx<key>@<host>:<port>` и нажмите **«Закрепить этот MLS»**.
   - **«Использовать каталог узла»** возвращает вариант по умолчанию.

После этого ваш постоянный адрес отображается как **«Постоянный адрес MAX#»**. Нажмите на него, чтобы скопировать полностью.

## 8. Добавление людей

Добавление человека — это **рукопожатие**. Вы представляетесь по его адресу. Он появляется в вашем списке, когда его устройство ответит. Если его устройство выключено, представление подождёт.

### 8.1 Android: отсканировать или вставить

1. Откройте вкладку **«Контакты»** и нажмите **«+ Добавить»**.
2. Затем:
   - нажмите **«Сканировать QR-код»** и наведите камеру на экран собеседника (в первый раз разрешите доступ к камере), или
   - вставьте его адрес в поле (он начинается с `Mx` или `MAX#`).
3. Нажмите **«Представиться»**.
4. Появится сообщение **«Представление отправлено — ожидаем ответа»**.

Человек появится в вашем списке, как только его устройство ответит.

Также можно нажать **три точки**, затем **«Сканировать QR-код»**. Отсканированный адрес попадёт на вкладку «Контакты».

### 8.2 Desktop: вставить

На компьютере камеры нет. Другие сканируют ваш код, а вы вставляете их адреса.

1. Откройте вкладку **«Контакты»** и нажмите **«Добавить контакт»**.
2. Вставьте адрес человека (`Mx<key>@<host>:<port>` или постоянный адрес вида `MAX#<key>#<location service>`).
3. Нажмите **«Представиться»**.
4. Появится сообщение «Представление отправлено. Контакт появится после ответа.»

### 8.3 Как поделиться контактом с кем-то ещё

Адрес одного контакта можно передать другому контакту в виде **карточки контакта**.

#### Как отправить карточку контакта (Android)

1. Откройте вкладку **«Контакты»** и нажмите на человека, контактом которого хотите поделиться.
2. Нажмите **«Отправить контакту…»**. (Кнопка **«Поделиться…»** рядом с ней вместо этого отправляет адрес через другое приложение.)
3. В окне **«Отправить {name}…»** нажмите на того, кто должен получить карточку.
4. Появится сообщение «Контакт отправлен: {name}».

#### Как отправить карточку контакта (Desktop)

1. Откройте вкладку **«Контакты»** и нажмите на человека, контактом которого хотите поделиться.
2. Нажмите **«Отправить контакту…»**.
3. Нажмите на того, кто должен получить карточку.

Чтобы вместо этого скопировать адрес самостоятельно, нажмите **«Копировать адрес для отправки»** в том же окне.

#### Как добавить человека из карточки контакта (Android)

1. В чате нажмите на карточку. На ней написано **«Полученный контакт»** и **«Нажмите, чтобы добавить контакт»**.
2. Появится окно «Добавить {name}?» с полным адресом этого человека.
3. Нажмите **«Добавить контакт»**, чтобы отправить ему представление. Или нажмите **«Копировать адрес»**, чтобы скопировать адрес полностью.
4. Появится сообщение «Знакомство отправлено — контакт появится после ответа».

### 8.4 Сведения о контакте

Нажмите на контакт на вкладке **«Контакты»**. Вы увидите:

- **«Сообщение»** — чтобы открыть чат.
- **«Адрес Parlons»** (в Desktop — **«Адрес Maxima»**) и все узлы, через которые с человеком можно связаться (**«Узел 1»**, **«Узел 2»** …). Нажмите, чтобы скопировать.
- **«Адрес для обмена (постоянный)»**, если он есть.
- **«Поделиться…»** (Android) или **«Копировать адрес для отправки»** (Desktop), а также **«Отправить контакту…»**
- **«Адрес для платежей (MINIMA)»**, после того как человек поделился адресом кошелька.
- **«Программа»** и **«Последняя активность»** (или **«Сейчас в сети»**).
- **«Удалить контакт»**.

#### Как удалить контакт (Android)

1. Откройте вкладку **«Контакты»** и нажмите на человека.
2. Прокрутите вниз и нажмите **«Удалить контакт»**.
3. Появится окно «Удалить {name}?». Нажмите **«Удалить»**.

#### Как удалить контакт (Desktop)

1. Откройте вкладку **«Контакты»** и нажмите на человека.
2. Нажмите **«Удалить контакт»**. Контакт сразу удаляется. Повторного вопроса нет.

Удаление убирает человека только из **вашего** списка. У него остаётся ваш адрес, и он по-прежнему может вам писать.

#### Как найти контакт

1. Откройте вкладку **«Контакты»**.
2. Введите часть имени в поле поиска (**«Поиск контактов»** на Android, **«Поиск»** в Desktop).
3. В списке останутся только подходящие люди.

### 8.5 Слова состояния рядом с контактами

| Слово | Значение |
|---|---|
| в сети / Сейчас в сети | Устройство человека сейчас доступно. |
| в сети … (время) | Когда устройство человека последний раз выходило на связь. |
| связь ещё не установлена | Вы отправили представление, но человек ещё не ответил. |
| адреса пока нет | Адрес этого человека неизвестен. |
| нет в ваших контактах | Вы общаетесь в чате с ключом, которого нет в вашем списке. |
| ядро / классика | Метка: постоянно работающий основной узел или пользователь классической Maxima. |

Пользователи классической Maxima могут с вами переписываться. Принимать звонки и воспроизводить голосовые сообщения они не могут.

### 9.3 Долгое нажатие на сообщение (Android)

#### Как скопировать, сохранить или проверить сообщение (Android)

1. Нажмите на облачко сообщения и удерживайте.
2. Выберите один из вариантов. Показываются только те, что подходят к этому сообщению:
   - **«Копировать сообщение»**, **«Копировать подпись»** или **«Копировать адрес контакта»**.
   - **«Копировать идентификатор транзакции»** — для платежа. Копируется полный идентификатор. Появится сообщение «ID транзакции скопирован».
   - **«Сохранить фото»** или **«Поделиться фото»** — для фото. После сохранения появится сообщение «Сохранено в Фото».
   - **«Информация»**: кто отправил, когда и в каком оно состоянии («Отправка…», «Отправлено (принято ретранслятором)», «Доставлено», «Прочитано», «Не удалось отправить»). Для платежа здесь также показывается полный **ID транзакции** и кнопка **«Копировать ID транзакции»**.

### 9.4 Щелчок правой кнопкой по сообщению (Desktop)

#### Как скопировать, открыть или проверить сообщение (Desktop)

1. Щёлкните сообщение правой кнопкой мыши.
2. Выберите один из пунктов. Показываются только те, что подходят к этому сообщению:
   - **«Копировать сообщение»**, **«Копировать подпись»** или **«Копировать адрес контакта»**.
   - **«Копировать идентификатор транзакции»** — для платежа. Копируется полный идентификатор.
   - **«Открыть изображение»** — для фото.
   - **«Информация»**. Показывает, кто отправил сообщение, время **«Отправлено:»** и **«Получено:»**, а также состояние. У сообщения, пришедшего с опозданием, написано «отправлено … · получено …».

### 9.5 Управление чатом

#### Как отметить чат прочитанным

1. Откройте вкладку **«Чаты»**.
2. Нажмите на чат и удерживайте (Android) или щёлкните его правой кнопкой мыши (Desktop).
3. Выберите **«Отметить прочитанным»**.

#### Как очистить чат

**«Очистить сообщения»** удаляет все сообщения этого чата **только на этом устройстве**. Сообщения у собеседников не удаляются, и выхода из группы не происходит. Отменить это нельзя.

1. Откройте вкладку **«Чаты»**.
2. Нажмите на чат и удерживайте (Android) или щёлкните его правой кнопкой мыши (Desktop).
3. Выберите **«Очистить сообщения»**.
4. Появится окно **«Очистить этот чат?»**. Подтвердите кнопкой **«Очистить»** (Android) или **«ОК»** (Desktop).

### 9.6 Поиск

#### Как искать (Android)

1. Нажмите на лупу в верхней панели. Или нажмите **три точки**, затем **«Поиск»**.
2. Введите запрос в поле **«Поиск сообщений…»**.
3. Результаты сгруппированы в разделы **«Контакты и группы»** и **«Сообщения»**. Нажмите на результат, чтобы открыть его.

#### Как искать (Desktop)

1. Нажмите на лупу в верхней панели. Приложение перейдёт на вкладку **«Чаты»**.
2. Введите запрос в поле **«Поиск по чатам»**. В списке чатов останутся только совпадения.
3. Нажмите на результат, чтобы открыть его.

### 9.7 Отчёты о прочтении

По умолчанию отчёты о прочтении **выключены**. Подтверждение доставки (две серые галочки) включено всегда. Это просто транспорт делает свою работу.

#### Как включить или выключить отчёты о прочтении

1. Откройте **«Настройки»** (Android: **три точки**, затем **«Настройки»**. Desktop: кнопка с **тремя точками**).
2. В разделе **«Конфиденциальность»** найдите **«Отчёты о прочтении»**.
3. Включите или выключите переключатель. Когда он включён, строка под ним гласит «Контакты видят, когда вы прочитали их сообщение». Когда выключен — «Контакты видят только доставку, но не прочтение».

Настройка действует для всех. Отдельной настройки для каждого контакта нет.

## 10. Группы

### Как работают группы

Групповое сообщение запечатывается **отдельно** для каждого участника и отправляется каждому из них. **Общего ключа группы нет.** Это означает:

- Удалённый участник исключается сразу. У него не остаётся ключа.
- Взлом ключей одного участника не открывает доступ к группе.
- Изменять состав группы может только **администратор**.
- Писать могут только текущие участники. Это проверяется при получении, а не только в приложении.

### Ограничения

| Ограничение | Значение |
|---|---|
| Участники | **До 12, включая вас.** |
| Звонки | Групповые звонки не поддерживаются. Звонки — только один на один. |
| Платежи | Платежи — только в личных чатах. |
| Приватные файлы | Разрешены. Участвовать могут только текущие участники. |

Если выбрать слишком много людей, появится сообщение «В группе может быть не более 12 человек, включая вас — выберите меньше».

### Как создать группу (Android)

1. Нажмите три точки в верхней панели, затем **«Новая группа»**.
2. В разделе **«Кто будет в группе?»** отметьте людей. Нажмите **«Далее»**.
3. В разделе **«Название группы»** введите название. Нажмите **«Создать»**.

Сначала нужен хотя бы один контакт. Нажмите **«Как работают группы»** в окне выбора, чтобы прочитать описанные выше правила.

### Как создать группу (Desktop)

1. На вкладке **«Чаты»** нажмите круглую кнопку **«Новый чат»**.
2. Нажмите **«Новая группа»** вверху списка.
3. Введите название в поле **«Название группы»**.
4. В разделе **«Кто будет в группе?»** отметьте хотя бы одного человека.
5. Нажмите **«Создать»**.

Нажмите **«Как работают группы»** в том же окне, чтобы прочитать описанные выше правила.

### Как изменить состав

Это может сделать только администратор. Вы — администратор группы, которую создали.

#### Как изменить состав (Android)

1. Откройте группу и нажмите кнопку **«Информация»**.
2. Нажмите **«Изменить состав»**. Эта кнопка видна, только если вы администратор.
3. В списке **«Участники»** отметьте или снимите отметку с людей.
4. Нажмите **«Сохранить»**.

#### Как изменить состав (Desktop)

1. Откройте группу и нажмите на её название вверху переписки.
2. Нажмите **«Изменить состав»**. Эта кнопка видна, только если вы администратор.
3. В списке **«Участники»** отметьте или снимите отметку с людей.
4. Нажмите **«Сохранить»**.

Вы всегда остаётесь в группе, где вы администратор. Если отметить слишком много людей, появится сообщение об ограничении в 12 человек, и ничего не изменится.

Кнопки «Покинуть группу» нет. Чтобы больше не видеть группу, воспользуйтесь **«Очистить сообщения»** ([раздел 9.5](#95-manage-a-chat)) или попросите администратора удалить вас.

## 11. Фото, голосовые сообщения и фотогалерея

### Ограничение размера

Фото, голосовое сообщение или другой медиафайл в сообщении может быть **не больше 16 МБ**. Для файла большего размера появится сообщение «Слишком большой файл: сообщение может содержать не более 16 МБ». Для больших файлов используйте **приватный файл** ([раздел 12](#12-private-files)).

### Как отправить фото (Android)

1. В чате нажмите **«Прикрепить»**, затем **«Фототека»**. Или нажмите кнопку **камеры**, чтобы сделать новый снимок.
2. Выберите фото или сделайте снимок.
3. В окне **«Отправить фото»** при желании добавьте подпись в поле **«Добавьте подпись…»**.
4. Нажмите **«Отправить»**. Появится сообщение «Отправка фото…».

### Как отправить фото (Desktop)

#### Как отправить фото из файла (Desktop)

1. В чате нажмите **«Прикрепить»**, затем **«Фото…»**.
2. Выберите файл изображения.
3. В окне **«Отправить фото»** при желании заполните поле **«Подпись (необязательно)»**.
4. Отправьте его.

#### Как вставить фото (Desktop)

1. Скопируйте снимок экрана или изображение либо файл изображения в файловом менеджере.
2. Щёлкните в области переписки.
3. Нажмите **Ctrl V** (**Command V** на Mac). Появится предпросмотр.
4. При желании добавьте подпись.
5. Выберите **«Отправить»** или **«Отмена»**.

Вставляемые изображения в буфере обмена ограничены 32 МБ до подготовки к отправке. Обычное копирование и вставка текста работают как всегда.

### Фотогалерея

Если нажать на любое фото в чате, откроется галерея всех фото этой переписки — отправленных и полученных — в порядке чата.

#### Как просматривать, сохранять фото и делиться ими (Android)

1. В чате нажмите на фото. Галерея откроется на нём.
2. Проводите пальцем в стороны, чтобы перейти к более новым или старым фото.
3. Сведите или разведите пальцы для масштабирования, перетаскивайте для перемещения, нажмите дважды для сброса.
4. Нажмите **«Сохранить»**, чтобы сохранить фото в «Фото», или **«Поделиться»**, чтобы отправить его через другое приложение.
5. Если на фото написано «Фото недоступно · нажмите, чтобы повторить», нажмите на него.
6. Чтобы выйти из галереи, используйте кнопку «Назад» или кнопку закрытия.

#### Как просматривать и сохранять фото (Desktop)

1. В чате нажмите на фото. Окно просмотра откроется на нём.
2. Нажимайте клавиши со стрелками влево и вправо или перетаскивайте в сторону, чтобы переходить между фото.
3. Колёсиком мыши меняйте масштаб, перетаскивайте для перемещения, дважды щёлкните для сброса.
4. Нажмите **«Сохранить изображение»**, чтобы сохранить копию.
5. Нажмите **Escape**, чтобы закрыть окно просмотра.

Галерея — это снимок на момент открытия. Закройте и снова откройте её, чтобы увидеть фото, пришедшие, пока она была открыта.

### Голосовые сообщения

#### Как записать голосовое сообщение (Android)

1. В чате с пустым полем сообщения нажмите кнопку **микрофона**. Или нажмите **«Прикрепить»**, затем **«Голосовое сообщение»**.
2. В первый раз разрешите доступ к микрофону.
3. Говорите. Таймер и волна показывают запись. Ограничение — **60 секунд**.
4. Нажмите **«Отправить»** или **«Отмена»**.

Если запись короче секунды, появится сообщение «Слишком коротко — запишите ещё немного».

#### Как записать голосовое сообщение (Desktop)

1. В чате нажмите **«Прикрепить»**, затем **«Голосовое сообщение»**.
2. Разрешите доступ к микрофону, если компьютер спросит. В окне отображается **●  Запись** и волна.
3. Говорите. Ограничение — **60 секунд**. По достижении предела запись останавливается и сообщение отправляется.
4. Нажмите **«Отправить»** или **«Отмена»**.

Если микрофона нет, появится сообщение «Микрофон недоступен.»

#### Как воспроизвести голосовое сообщение

1. Нажмите **«Воспроизвести»** на голосовом сообщении.
2. Нажмите ещё раз, чтобы остановить.

Голосовые сообщения требуют Parlons у обеих сторон; контакт на классической Maxima не может их получить.

## 12. Приватные файлы

Приватные файлы позволяют отправить в чате файл размером до **512 МБ**. Файл шифруется новым ключом и отправляется зашифрованными частями **напрямую между участниками переписки**. Нет ни центрального сервера, ни публичного каталога.

### Как отправить приватный файл

#### Как отправить приватный файл (Android)

1. В чате нажмите **«Прикрепить»**, затем **«Приватный файл»**.
2. Выберите файл (до 512 МБ).
3. Окно **«Отправка приватного файла»** показывает «Подготовка…», пока файл шифруется. Нажмите **«Скрыть»**, чтобы закрыть окно; работа продолжится.

#### Как отправить приватный файл (Desktop)

1. В чате нажмите **«Прикрепить»**, затем **«Приватный файл…»**.
2. В окне **«Отправить приватный файл (до 512 МБ)»** выберите файл.

В чате появится карточка файла с названием и размером.

### Как получить приватный файл

Получение **не** начинается само. Решаете вы.

#### Как получить приватный файл

1. Нажмите на карточку файла. На ней написано «Нажмите «Скачать», чтобы получить зашифрованный файл. До завершения передачи хотя бы один участник должен оставаться в сети.»
2. Нажмите **«Скачать»**.
3. Подождите. Состояние последовательно меняется: **«Подключение»**, **«Загрузка»** и **«Проверка»**.
4. Когда появится **«Готово»** или **«Готово · раздача»**, нажмите **«Сохранить файл…»**.
5. Выберите, куда сохранить файл. Появится сообщение «Файл сохранён».

### Управление передачей

#### Как приостановить, возобновить, сохранить или удалить передачу

1. В чате нажмите **«Прикрепить»**, затем **«Передача файлов»**. Вы увидите все передачи, которые хранит это устройство. (Или нажмите на саму карточку файла.)
2. Нажмите на передачу.
3. Воспользуйтесь нужной кнопкой:

| Кнопка | Что делает |
|---|---|
| **«Приостановить раздачу»** / **«Возобновить»** | Остановить или снова запустить эту передачу. |
| **«Сохранить файл…»** | Сохранить готовый файл. |
| **«Удалить локальную передачу»** | Удалить передачу на этом устройстве и прекратить раздачу. Сохранённые вами копии останутся. Сначала появится вопрос. Подтвердите (на Android кнопка называется **«Удалить»**). |

Если передач нет, вы увидите «Локальных передач файлов нет».

Пока вы скачиваете файл, ваше устройство может также **отправлять зашифрованные части** другим участникам чата. Это помогает всем быстрее завершить загрузку.

После перезапуска активные передачи **возобновляются сами**. Приостановленные вами передачи остаются приостановленными.

### Слова состояния

| Состояние | Значение |
|---|---|
| Подготовка | Файл шифруется. |
| Ожидание участников | Пока никто из тех, у кого есть файл, не доступен. |
| Подключение / Загрузка / Проверка | Идёт передача. |
| Готово · раздача | Файл у вас, и вы помогаете другим его получить. |
| Готово · приостановлено | Файл у вас; раздача приостановлена. |
| Приостановлено / Ошибка | Остановлено. Нажмите **«Возобновить»**, чтобы попробовать снова. |

### Ограничения и условия

| Ограничение | Значение |
|---|---|
| Один файл | 512 МБ |
| Данные передач, хранимые на устройстве | 2 ГБ |
| Хранимых передач | 32 |
| Одновременно активных передач | 4 |

- **Хотя бы один участник чата должен быть доступен** — либо напрямую из интернета ([раздел 19](#19-the-network-tab-relays-and-helping-the-network)), либо в той же локальной сети. Если никто не доступен, передача ждёт. Центрального сервера, который мог бы подстраховать, нет.
- **У обеих сторон должна быть версия Parlons с поддержкой приватных файлов.** Старое приложение покажет «Приватный файл · обновите Parlons для открытия».
- Если у кого-то уже есть файл и его ключ, забрать их обратно нельзя.
- Участники передачи видят интернет-адреса друг друга. Приватные файлы зашифрованы, но не анонимны.

## 13. Голосовые и видеозвонки

Звонки работают в **приложении для Android** и в **Parlons Cloud для Android**. Parlons Desktop не передаёт звук и видео звонков: он показывает входящий звонок («Ответьте на телефоне — настольное приложение пока не передаёт звук и видео вызовов.») и вежливо отклоняет его, чтобы у звонящего не продолжались гудки. Кнопки **«Видеозвонок»** и **«Голосовой звонок»** в Desktop только объясняют это. В приложении для iPhone звонков пока нет.

### Как позвонить (Android)

1. Откройте **личный** чат.
2. Нажмите **«Голосовой звонок»** или **«Видеозвонок»** в заголовке чата.
3. Когда появится запрос, разрешите доступ к микрофону (и к камере для видеозвонка).
4. На экране появится **«Вызов…»**, затем **«Подключение…»**, а затем начнётся звонок.

Во время звонка:

| Кнопка | Что делает |
|---|---|
| **«Выключить микрофон»** / **«Включить микрофон»** | Ваш микрофон. |
| **«Динамик»** / **«Телефон»** | Откуда идёт звук. |
| **«Камера»** | Переключение между фронтальной и основной камерой (видео). |
| **«Отбой»** | Завершить звонок. |

### Как ответить на звонок (Android)

Входящий звонок звучит вашей мелодией и показывает **«Входящий звонок Parlons»** или **«Входящий видеозвонок Parlons»**. Он может отображаться поверх экрана блокировки. Если на звонок не ответить, он перестаёт звонить примерно через 45 секунд.

1. Нажмите **«Ответить»**, чтобы принять звонок, или **«Отклонить»**, чтобы отказаться.
2. Если появится запрос, разрешите доступ к микрофону (и к камере для видеозвонка).
3. Пользуйтесь кнопками звонка, как описано выше. Нажмите **«Отбой»**, чтобы завершить звонок.

#### Как сделать так, чтобы звонки отображались на экране блокировки (Android)

1. Откройте **«Настройки»** (**три точки**, затем **«Настройки»**).
2. В разделе **«Конфиденциальность»** найдите **«Входящие звонки»**.
3. Если там написано «Разрешите полноэкранные уведомления, чтобы видеть звонки на экране блокировки», нажмите на строку (на ней показано **«РАЗРЕШИТЬ»**) и дайте разрешение на открывшемся экране Android.
4. После этого в строке будет написано «Мелодия, вибрация и уведомления о звонках» и показано **«НАСТРОЙКИ»**. Нажмите, чтобы выбрать мелодию и вибрацию.

### Ограничения звонков

- Звонки — только **один на один**. «Групповые звонки пока не поддерживаются».
- Parlons должен быть у обоих собеседников. «Для звонков оба собеседника должны использовать Parlons».
- Для звонка устанавливается **прямое** соединение между двумя устройствами. Parlons не передаёт звук звонка через сервер-ретранслятор. Некоторые сети (некоторые мобильные операторы, некоторые строгие роутеры) блокируют прямые соединения. Тогда появится **«Не удалось подключиться»** или **«Не удалось установить соединение»**. Попробуйте ещё раз, когда один или оба собеседника будут подключены к Wi-Fi.

История звонков отображается в чате, например «Голосовой звонок · 2:35», **«Пропущенный звонок»**, **«Нет ответа»**, **«Занято»** или «Отвечено на другом устройстве».

## 14. Ссылки в чатах

Веб-ссылки в сообщениях и подписях к фото **кликабельны**. Это относится к `http://`, `https://`, `www.` и просто к доменным именам (они открываются по HTTPS).

#### Как открыть ссылку

1. Нажмите на ссылку в сообщении.
2. Она откроется в вашем обычном браузере.

#### Как скопировать ссылку или поделиться ею (Android)

1. Нажмите на ссылку и удерживайте.
2. Нажмите **«Открыть ссылку»**, **«Копировать ссылку»** или **«Поделиться ссылкой»**.

#### Как скопировать ссылку или поделиться ею (Desktop)

1. Щёлкните ссылку правой кнопкой мыши.
2. Выберите **«Открыть ссылку»**, **«Копировать ссылку»** или **«Скопировать ссылку для отправки»**.
3. После **«Скопировать ссылку для отправки»** вставьте ссылку в переписку или приложение, где хотите ею поделиться.

Parlons никогда не загружает предпросмотр ссылок и никогда не выполняет HTML или форматирование из полученного сообщения. Ничего не загружается, пока вы не нажмёте.

## 15. Платежи: Minima и MxUSD

Ваши 24 слова — это ещё и кошелёк Minima. Parlons может отправлять деньги двух видов:

- **Minima** — собственная монета сети.
- **MxUSD** — долларовый токен Minima. Его идентификатор токена:

  ```
  0x7D39745FBD29049BE29850B55A18BF550E4D442F930F86266E34193D89042A90
  ```

Платежи **настоящие**, и **отменить их нельзя**. Транзакции создаются и подписываются **на вашем устройстве**. Устройство покидает только подписанная транзакция.

### 15.1 Оплата в чате (Android)

1. Откройте **личный** чат. В группах платежи недоступны.
2. Нажмите **«Прикрепить»**, затем **«Отправить платёж»**.
3. В окне **«Оплатить: {name}»** выберите **Minima** или **MxUSD**.
4. Введите сумму в поле **«Сумма (MINIMA)»** или **«Сумма (MxUSD)»** и, при желании, **«Примечание (необязательно)»**.
5. Нажмите **«Отправить»**. В окне подтверждения написано «Отправить {amount} {token}?» и «Будет подписана и отправлена в сеть настоящая транзакция. Отменить её нельзя.»
6. Нажмите **«Подтвердить»**. Появится «Подписание платежа…», затем **«Платёж отправлен»**.

В чате появится облачко платежа. Нажмите на него и удерживайте, затем нажмите **«Копировать идентификатор транзакции»**, чтобы скопировать полный идентификатор.

Если вы видите «Адреса кошелька ещё нет — попросите собеседника открыть этот чат», приложение собеседника ещё не передало вам адрес своего кошелька. Попросите его открыть чат с вами.

### 15.2 Оплата в чате (Desktop)

1. Откройте личный чат с контактом. Нажмите **«Прикрепить»**, затем **«Отправить платёж»**.
2. В окне написано **«Кому: {name}»**. Выберите **Minima** или **MxUSD**.
3. Введите **сумму** и, при желании, **примечание (необязательно)**.
4. Нажмите **«Подписать и отправить»**.

В чате появится «↑ Вы отправили» или «↓ Вы получили». Щёлкните платёж правой кнопкой мыши и выберите **«Копировать идентификатор транзакции»**, чтобы скопировать полный идентификатор.

Если вы видите «У этого контакта пока нет адреса кошелька. Он должен поделиться им.», попросите его открыть чат с вами в своём приложении.

### 15.3 Вкладка «Кошелёк»

На вкладке «Кошелёк» (Android и Desktop) есть два режима: **«Баланс»** и **«История»**. Нажмите на любое из названий вверху, чтобы переключиться.

В режиме **«Баланс»** показаны:

- Ваш общий баланс и сумма, **доступная сейчас**. Монеты, которые ещё подтверждаются, пока нельзя отправить.
- **ВАШИ ТОКЕНЫ** (Desktop: **«Токены»**), включая MxUSD.
- **«Использовано подписей»**: «Осталось подписей: {remaining} из {maximum} · каждая отправка расходует одну». См. [раздел 15.4](#154-signature-uses-read-this-before-you-import-a-phrase).
- **«Отправить»** и **«Получить»**.

#### Как разблокировать монеты, которые ещё синхронизируются (Android)

1. Откройте вкладку **«Кошелёк»**.
2. Если в строке под балансом написано «Доступно … · нажмите «Синхронизировать», чтобы разблокировать остальное», нажмите на эту строку.
3. Появится «Синхронизация монет…», затем «Монеты синхронизированы — теперь доступно: …».

#### Как посмотреть сведения о токене

1. Откройте вкладку **«Кошелёк»** в режиме **«Баланс»**.
2. Нажмите на токен в разделе **«ВАШИ ТОКЕНЫ»** (Desktop: **«Токены»**).
3. Вы увидите его полный **«ID токена»**, **«Общий объём выпуска»** и **«Монеты»**. Нажмите на ID токена, чтобы скопировать его.

#### Как получить Minima или MxUSD

1. Откройте вкладку **«Кошелёк»**.
2. Нажмите **«Получить»**.
3. В окне **«Получить MINIMA»** показан ваш полный адрес Minima и QR-код.
4. Нажмите на адрес, чтобы скопировать всю строку, или дайте отправителю отсканировать QR-код.

На этот адрес кто угодно может отправить Minima или MxUSD.

#### Как отправить на адрес (Android)

1. Откройте вкладку **«Кошелёк»** и нажмите **«Отправить»**.
2. Введите адрес в поле (он начинается с `Mx` или `0x`) или нажмите кнопку сканирования, чтобы отсканировать его.
3. Выберите **Minima** или **MxUSD**.
4. Введите сумму.
5. Нажмите **«Подписать и отправить»**. Появятся «Выбор монет…», «Подписание на этом устройстве…», «Публикация через …», затем «Отправлено — включается в блок».

#### Как отправить на адрес (Desktop)

1. Откройте вкладку **«Кошелёк»** и нажмите **«Отправить»**.
2. Вставьте адрес в поле **«Адрес Mx…»**.
3. Выберите **Minima** или **MxUSD**.
4. Введите **сумму**.
5. Нажмите **«Подписать и отправить»**. Появится «Выбор монет…», затем «Публикация через …».

«Включается в блок» — это нормально. Платёж подтверждается, когда попадает в блок.

#### Как посмотреть историю платежей

1. Откройте вкладку **«Кошелёк»** и нажмите **«История»**.
2. Нажмите **«Все»**, **«Отправлено»** или **«Получено»**, чтобы отфильтровать список.
3. Нажмите на платёж. Вы увидите его **«Направление»**, **«Сумма»**, **«Токен»**, **«Дата и время»**, полный адрес **«Кому»** или **«От кого»** и полный **«ID транзакции»**.

### 15.4 Использования подписей: прочитайте перед импортом фразы

Кошельки Minima подписывают одноразовыми ключами. Каждый ключ может подписывать ограниченное число раз. Parlons ведёт учёт использований, чтобы никогда не использовать ключ повторно. Повторное использование одноразового ключа подписи может его раскрыть и привести к потере денег.

- Счётчик **только растёт**.
- Подписание резервирует одно использование, даже если платёж не завершится.
- Восстановление только по словам не может знать старое значение. Его содержит зашифрованная резервная копия ([раздел 20](#20-backups-and-moving-to-a-new-device)).

#### Как увеличить счётчик подписей (Android)

Делайте это, только если знаете, что эта сид-фраза подписывала больше раз в другом месте.

1. Откройте вкладку **«Кошелёк»** в режиме **«Баланс»**.
2. Нажмите и удерживайте карточку **«Использования ключа»** (на ней написано **«Использовано подписей»** и **«Удерживайте для изменения»**).
3. В окне **«Указать число использованных подписей»** введите число не меньше, чем количество использований этой сид-фразы где бы то ни было.
4. Нажмите **«Задать»**. Появится «Установлено: …».

Уменьшить значение нельзя. Если ввести меньшее число, появится «Без изменений — можно только повысить выше …». Нажмите **«Отмена»**, чтобы вместо этого прочитать **«Почему это важно»**.

В Desktop нажмите **?** рядом с **«Использовано подписей»** (**«О расходовании подписей»**), чтобы прочитать то же пояснение. В кошельке Desktop нет элемента для увеличения счётчика.

### 15.5 Настройки кошелька (Android)

Откройте вкладку **«Кошелёк»**, прокрутите вниз и нажмите **«Настройки кошелька»**. На панели указано, какую сид-фразу сейчас использует кошелёк.

#### Как использовать собственный узел кошелька (Android)

По умолчанию кошелёк читает блокчейн через сеть узлов Minima от Parlons с автоматическим переключением при сбоях. Вместо этого можно указать собственный Parlons Node. Ваша сид-фраза никогда не покидает телефон.

1. В **«Настройках кошелька»** нажмите **«Узел кошелька»**.
2. Введите адрес конечной точки вашего узла в первое поле (он выглядит как `https://your-node…/cmd`), а его **токен доступа** — во второе.
3. Нажмите **«Сохранить узел»**. Появится «Узел кошелька сохранён».

Чтобы отменить это, снова откройте **«Узел кошелька»** и нажмите **«Вернуться к сети узлов Parlons»**. Конечная точка и токен описаны в [руководстве Parlons Node](parlons-node.md#14-the-wallet-gateway-and-its-token).

#### Как импортировать другую фразу кошелька (Android)

Это заменяет сид-фразу кошелька другой фразой из 12 или 24 слов. Адрес и средства меняются. Ваша личность в чате не меняется. Импортируйте только ту фразу, ключ которой **не** подписывал в другом кошельке или на другом узле.

1. В **«Настройках кошелька»** нажмите **«Импортировать фразу»**.
2. В окне **«Импортировать сид-фразу кошелька»** прочитайте предупреждение.
3. Введите фразу в поле **«Сид-фраза из 12 / 24 слов»**.
4. Нажмите **«Импортировать»**. Появится «Импорт сид-фразы кошелька…».

#### Как вернуться к сид-фразе Parlons (Android)

1. В **«Настройках кошелька»** нажмите **«Использовать сид-фразу Parlons»**.
2. Появится окно **«Использовать сид-фразу Parlons?»**. Нажмите **«Использовать сид-фразу Parlons»**.
3. Появится «Возврат к сид-фразе Parlons…».

Импортированный кошелёк не удаляется. Чтобы вернуться к нему, снова импортируйте его фразу.

### 15.6 Проблемы с платежами

| Сообщение | Что делать |
|---|---|
| Недостаточно подтверждённых средств. | Дождитесь подтверждения входящих монет. На Android нажмите строку «нажмите «Синхронизировать», чтобы разблокировать остальное» под балансом. |
| Недопустимый адрес Mx. / ошибка контрольной суммы | Скопируйте адрес ещё раз, полностью. |
| Это адрес сжигания. | Вы ввели адрес, который уничтожает монеты. Проверьте адрес. |
| Платежи пока доступны только в личных чатах | Откройте личный чат. |
| ⚠ не подтверждено — проверьте баланс перед повторной оплатой | Платёж, возможно, ещё подтверждается. Проверьте баланс и историю, прежде чем отправлять снова. |

## 16. Языки

Parlons говорит на **английском**, **упрощённом китайском (简体中文)**, **русском (Русский)** и **украинском (Українська)**. Переведён каждый экран — на Android, в Desktop, Parlons Cloud и на iPhone.

### Как изменить язык

При первом запуске на Android приложение просит выбрать язык. После этого используйте следующие шаги.

#### Как изменить язык (Android)

1. Откройте **«Настройки»** (**три точки**, затем **«Настройки»**).
2. На первой карточке написано «Выберите язык для этого устройства.» Нажмите кнопку **English · 简体中文 · Русский · Українська**.
3. Нажмите на свой язык. Приложение переключится без перезапуска.

На экране приветствия, пока личности ещё нет, вместо этого нажмите **«Изменить язык»**.

#### Как изменить язык (Desktop)

1. Откройте **«Настройки»** (кнопка с **тремя точками**).
2. В разделе **«Язык»** нажмите **«Изменить язык»**.
3. Нажмите на свой язык.

Также можно выбрать **«Изменить язык»** в меню значка в трее или в строке меню.

Язык настраивается только на этом устройстве. Ваши контакты видят сообщения точно такими, какими вы их написали.

## 17. Уведомления

### Android

Разрешите уведомления, когда Parlons попросит. На Android 13 и новее без этого разрешения уведомлений о сообщениях **не будет**.

#### Как снова включить уведомления (Android)

Если в первый раз вы отказали:

1. Откройте приложение **«Настройки»** Android.
2. Перейдите в **«Приложения»**, затем **Parlons!**, затем **«Уведомления»**. (Точные названия немного различаются у разных производителей телефонов.)
3. Включите уведомления.

Parlons использует отдельные каналы уведомлений, которые можно настроить на том же экране Android:

| Канал | Для чего |
|---|---|
| Сообщения | Новые сообщения. |
| Сообщения (без звука) | Новые сообщения, когда звук Parlons выключен. |
| Входящие звонки | Входящие звонки с кнопками «Ответить» и «Отклонить». |
| Уведомление о транспорте | Показывает, что Parlons работает и сколько ретрансляторов подключено. Оно поддерживает подключение. |

#### Как включить или выключить звук сообщений (Android)

1. Откройте **«Настройки»** (**три точки**, затем **«Настройки»**).
2. В разделе **«Конфиденциальность»** найдите **«Звук сообщений»**.
3. Включите переключатель для режима «Звук Pssst! при получении сообщения». Выключите для режима «Без звука — уведомления и вибрация остаются».

#### Как сделать так, чтобы уведомления приходили вовремя (Android)

1. Откройте **«Настройки»**.
2. В разделе **«Узел и питание»** посмотрите на **«Исключение из оптимизации батареи»**.
3. Если там написано **«не настроено»**, нажмите **«Настроить батарею»**.
4. В открывшемся окне Android разрешите Parlons работать в фоне. Теперь в строке написано **«разрешено»**.
5. Откройте вкладку **«Сеть»** и проверьте, что подключён хотя бы один узел.

### Desktop

Пока приложение работает, Desktop показывает уведомление о новом сообщении.

#### Как включить или выключить звук сообщений (Desktop)

1. Откройте **«Настройки»** (кнопка с **тремя точками**).
2. В разделе **«Конфиденциальность»** найдите **«Звук сообщений»**.
3. Включите его для режима «Звук Pssst! при получении сообщения» или выключите для режима **«Без звука»**.

#### Как включить блокировку приложения (Android)

Сначала на телефоне должна быть настроена блокировка экрана (PIN-код, графический ключ, пароль или отпечаток пальца). Иначе в строке будет написано «Для этой функции настройте блокировку экрана устройства».

1. Откройте **«Настройки»**.
2. В разделе **«Конфиденциальность»** включите **«Блокировка приложения»**.

4. Появится «Блокировка приложения включена». Теперь при открытии Parlons будет запрашивать отпечаток пальца или PIN-код.

Чтобы выключить её, выключите тот же переключатель и подтвердите, что это вы. Появится «Блокировка приложения выключена».

#### Как скрыть Parlons от демонстрации экрана (Android)

1. Откройте **«Настройки»**.
2. В разделе **«Конфиденциальность»** выключите **«Разрешить демонстрацию экрана»**.
3. Теперь в строке написано «При включённой блокировке приложения экран скрыт от трансляции».

Это действует, только пока включена **«Блокировка приложения»**.

#### Как отметить этот телефон как основной узел (Android)

1. Откройте **«Настройки»**.
2. В разделе **«Узел и питание»** включите **«Работать как основной узел»**.
3. Теперь контакты видят рядом с вами «ядро», а не обычный телефон.

#### Как переключиться на классический движок (Android)

Не включайте это, если не уверены, что это нужно. Приватным файлам нужен встроенный движок.

1. Откройте **«Настройки»**.
2. В разделе **«Узел и питание»** включите **«Классический движок»**.
3. Появится «Смена движка — Parlons скоро перезапустится». Parlons перезапустится сам.

Чтобы вернуться, снова выключите переключатель. Контакты, добавленные на классическом движке, сохранятся.

#### Как разрешить или отозвать доступ другого приложения (Android)

Другое приложение на телефоне может попросить использовать вашу личность Parlons как транспорт. Оно появится в разделе **«Приложения, использующие Maxima»** с пометкой **«ожидает одобрения»**.

1. Откройте **«Настройки»** и прокрутите до раздела **«Приложения, использующие Maxima»**.
2. Нажмите на приложение с надписью «{app} запрашивает доступ».
3. Появится окно «Разрешить {app} использовать Parlons?». Нажмите **«Разрешить»** или **«Отклонить»**.

Чтобы позже отозвать доступ:

1. Нажмите на приложение с надписью «Одобрено — нажмите, чтобы отозвать».
2. Появится окно «Отозвать доступ {app}?». Нажмите **«Отозвать»**.

Нажмите **?** рядом с **«Приложения, использующие Maxima»**, чтобы прочитать простое пояснение.

## 19. Вкладка «Сеть»: ретрансляторы и помощь сети

Трогать эту вкладку не обязательно. Она нужна, чтобы вы могли видеть, что происходит, и при необходимости исправить проблему.

### 19.1 Подключение (Android)

Верхняя карточка показывает **«Доступен»**, **«Запуск»** или **«Не в сети»**, а также **«Подключённые узлы»** — ретрансляторы, которые передают ваш трафик прямо сейчас. «Независимые пути к вам. Чем их больше, тем надёжнее.»

Другие счётчики:

| Счётчик | Значение |
|---|---|
| Ваши исходящие сообщения | Ваши сообщения, ожидающие, пока их примет ретранслятор. Если число никогда не уменьшается, значит, ни один ретранслятор не доступен. |
| Почтовый ящик для других | Зашифрованные сообщения, которые этот телефон хранит для людей не в сети. Прочитать их он не может. |
| Обслуживаемые запросы | Поиски и подтверждения, на которые этот телефон отвечает для других. |

Нажмите на любой счётчик, чтобы прочитать короткое пояснение.

#### Как быстро переподключиться (Android и Desktop)

1. Откройте вкладку **«Сеть»**.
2. Нажмите **«Автоподключение»** в верхней карточке. Пока идёт процесс, отображается **«Выполнение…»**.
3. Приложение перебирает известные ему ретрансляторы, а затем пытается сделать вас доступным напрямую. Подсказка сообщит, через сколько ретрансляторов вы подключены.

### 19.2 Ретрансляторы (узлы)

В Parlons встроен список ретрансляторов, а кроме того, приложение узнаёт о ретрансляторах из сети.

Ретранслятором может служить любой публичный узел Maxima, в том числе классический узел Minima с включённой Maxima.

#### Как добавить ретранслятор, которому вы доверяете (Android)

1. Откройте вкладку **«Сеть»** и найдите **«Узлы · передают ваш трафик»**.
2. Введите `host:port` в поле **«добавить ретранслятор: хост:порт»** или вставьте текст QR-кода ретранслятора.
3. Нажмите **«Добавить и подключиться»**.
4. Появится окно **«Добавить и подключиться?»**. Нажмите **«Подключиться»**. Транспорт перезапустится. Ваши чаты и кошелёк это не затронет.
5. Через несколько секунд появится окно **«Подключено»** (или **«Переподключение»**, если ретранслятор вас ещё не принял). Нажмите **«ОК»**.

Чтобы вместо этого отсканировать QR-код ретранслятора, нажмите **«Управление»**, затем **«Сканировать QR-код ретранслятора»** и наведите на него камеру.

#### Как управлять ретрансляторами (Android)

1. Откройте вкладку **«Сеть»**. В разделе **«Узлы · передают ваш трафик»** нажмите **«Управление»**.
2. На панели **«Управление узлами»** показан список **«Настроенные узлы»**. У каждого указано «встроенный» или «добавлен вами», а также **«Подключено»** или **«Ожидание»**.
3. Рядом с ретранслятором нажмите:
   - **«Подключиться»**, чтобы сразу подключиться к неактивному ретранслятору.
   - **«QR»**, чтобы поделиться им (см. ниже).
   - **«Удалить»**, чтобы убрать его.
4. Нажмите **«Сбросить настройки»** внизу, чтобы вернуть встроенный список.

Должен остаться хотя бы один ретранслятор. Если попытаться удалить последний, появится «Оставьте хотя бы один ретранслятор — добавьте свой, прежде чем удалять этот».

#### Как выключить или включить встроенные ретрансляторы (Android)

1. Откройте вкладку **«Сеть»** и нажмите **«Управление»**.
2. Выключите **«Использовать встроенные ретрансляторы»**. Теперь используются только добавленные вами ретрансляторы или те, что запомнил этот телефон.
3. Включите снова, чтобы использовать встроенный список вместе с вашими.

Если у вас нет собственного ретранслятора, появится «Сначала добавьте свой ретранслятор — телефону нужен адрес для первого подключения».

#### Как поделиться ретранслятором (Android)

1. Откройте вкладку **«Сеть»** и нажмите **«Управление»**.
2. Нажмите **«QR»** рядом с ретранслятором.
3. Панель **«Поделиться ретранслятором»** показывает QR-код. Любой, кто его отсканирует, добавит этот ретранслятор к своим. Под ним в поле **«Текст для отправки»** показан полный текст; нажмите, чтобы скопировать его.

#### Как добавлять ретрансляторы и управлять ими (Desktop)

1. Откройте вкладку **«Сеть»**. Найдите **«Узлы · передают ваш трафик»**.
2. Чтобы добавить ретранслятор, введите `host:port` (или вставьте текст QR-кода ретранслятора) в поле **«добавить ретранслятор: хост:порт»** и нажмите **«Добавить и подключиться»**.
3. У каждого ретранслятора в списке указано «встроенный», «добавлен вами» или «обнаружен». Рядом с ним нажмите **«QR»**, чтобы поделиться им, **«Подключиться»**, чтобы подключиться сейчас, или **«Удалить»**, чтобы убрать его.
4. Используйте переключатель встроенных ретрансляторов. На нём написано «Встроенные ретрансляторы: включены (из приложения и добавленные вами)» или «Встроенные ретрансляторы: выключены (только добавленные вами или сохранённые этим компьютером)».
5. Нажмите **«Сбросить настройки»**, чтобы вернуть встроенный список.

### 19.3 Помощь сети (Android)

Parlons работает, только если достаточно людей передают трафик. На вкладке «Сеть» переключатель **«Помогать сети»** по умолчанию **включён**. Он делает максимум того, что телефон может безопасно делать, в три этапа, за которыми можно следить:

| Этап | Что это значит | Когда работает |
|---|---|---|
| **Помощь сети** | Хранит зашифрованную почту для людей не в сети, отвечает на поиски, подписывает подтверждения доставки, хранит небольшие зашифрованные фрагменты. | Почти всегда. Ресурсоёмкие задачи приостанавливаются в мобильной сети, если включено **«Только Wi-Fi»** (по умолчанию включено). Приостанавливается при низком заряде батареи. |
| **Доступен напрямую** | Телефон получает настоящий публичный адрес, и контакты связываются с вами на один шаг короче. | Только по Wi-Fi, во время зарядки и только если роутер открывает порт. |
| **Ретранслятор ⚡** | Телефон передаёт запечатанный трафик других людей через порт **9535**. | Только по Wi-Fi, во время зарядки и при заряде батареи от 60%. Останавливается, когда вы отключаете зарядку. |

Ничто из этого не стоит вам сообщений. Если роутер не открывает порт, вы, как всегда, остаётесь доступны через ретрансляторы. Приложение сообщает, почему этап не работает, например «Ретранслятору нужен Wi-Fi», «Подключите зарядку для передачи чужого трафика» или «Зарядите выше 60%, чтобы включить ретранслятор».

#### Как включить или выключить «Помогать сети» (Android)

1. Откройте вкладку **«Сеть»**.
2. В разделе **«Помогать сети»** включите или выключите переключатель **«Помогать сети»**.
3. Когда он включён, следите за тремя этапами под переключателем: **«Помощь сети»**, **«Доступен напрямую»** и **«Ретранслятор ⚡»**. Если этап не работает, подсказка под ними объясняет почему и что делать, например **«Открыть настройки Wi-Fi»**.

#### Как разрешить ресурсоёмким задачам работать в мобильной сети (Android)

1. Откройте вкладку **«Сеть»**.
2. В разделе **«Помогать сети»** выключите **«Только Wi-Fi»**. Строка изменится на «Ресурсоёмкие задачи выполняются в любой сети».
3. Включите снова, чтобы ресурсоёмкие задачи выполнялись только по Wi-Fi («Ресурсоёмкие задачи приостанавливаются в мобильной сети»).

#### Как узнать, что настроить на роутере (Android)

1. Откройте вкладку **«Сеть»**.
2. Найдите карточку **«Телефон в вашей сети · что пробрасывать»**. На ней показаны **«Этот телефон (локальная сеть)»**, **«Ваш роутер»**, **«Ваш публичный адрес»**, а когда применимо — **«Правило маршрутизатора для прямого доступа»** и **«Правило маршрутизатора для ретранслятора»**. Нажмите на любой пункт, чтобы скопировать его.
3. Нажмите **«Открыть страницу управления маршрутизатором»**, чтобы открыть роутер в браузере.

#### Как настроить ручной проброс порта (Android)

Используйте это, если роутер не открывает порт сам.

1. Откройте вкладку **«Сеть»** и найдите **«Прямая доступность · публичный адрес, когда это возможно»**.
2. Нажмите **«Ручной проброс порта»**. Откроется панель **«Ручной проброс порта»**.
3. В разделе **«Проброс на этот телефон»** показаны локальный адрес и порт. По умолчанию порт — **9536**. Его можно изменить в поле **«Порт для проброса»**. Порт 9535 зарезервирован для режима ретранслятора.
4. На роутере добавьте правило, которое перенаправляет этот **TCP**-порт на этот локальный адрес.
5. Вернувшись на панель, проверьте **«Ваш публичный IP (определяется автоматически)»**. Если он неверен, исправьте.
6. Нажмите **«Включить и проверить»**. Появится «Проверка …». Если всё работает, появится «Вы доступны напрямую», а кнопка на вкладке «Сеть» будет называться **«Ручной проброс · включён»**.

Чтобы отключить, снова откройте панель и нажмите **«Выключить ручной проброс»**.

Если по-прежнему не работает, скорее всего, ваш интернет-провайдер использует один публичный адрес для многих абонентов (NAT операторского уровня, CGNAT). Никакой проброс этого не исправит. Вы останетесь на связи через ретрансляторы.

### 19.4 Помощь сети (Desktop)

На вашем компьютере ничего не принимает входящие подключения, пока вы не включите одну из этих функций. В Windows брандмауэр спросит один раз; разрешите.

#### Как сделать компьютер доступным напрямую (Desktop)

1. Откройте вкладку **«Сеть»** и найдите **«Прямая доступность · публичный адрес, когда это возможно»**.
2. Нажмите **«Проверить доступ извне»**. Parlons запросит у роутера публичный порт и проверит его извне, прежде чем сообщать о нём другим.
3. Если всё работает, появится ваш **«Публичный адрес»**. Кнопка теперь называется **«Проверить снова»**.
4. Если роутер отказывает, настройте ручной проброс порта (см. далее).

#### Как настроить ручной проброс порта (Desktop)

1. На вкладке **«Сеть»** нажмите **«Ручной проброс порта»**.
2. В разделе **«Перенаправить на этот компьютер»** показаны локальный адрес и порт. При необходимости измените порт в поле **«Порт для проброса»**. Порт 9535 зарезервирован для режима ретранслятора.
3. На роутере добавьте правило, которое перенаправляет этот **TCP**-порт на этот локальный адрес.
4. Проверьте **«Ваш публичный IP (определяется автоматически)»** или введите его.
5. Нажмите **«Включить и проверить»**. Появится «Включено — проверка … извне…». Затем кнопка будет называться **«Ручной проброс порта · вкл.»**.

Чтобы отключить, снова откройте окно и нажмите **«Выключить ручной проброс»**.

#### Как сделать компьютер ретранслятором (Desktop)

1. Откройте вкладку **«Сеть»** и найдите **«Помогать сети»**.
2. Включите **«Работать ретранслятором»**. Компьютер будет передавать запечатанный трафик других людей через порт 9535 и расширять сеть.
3. Карточка показывает «Вы передаёте трафик других участников через порт 9535», а также **«Подключённые клиенты»** и **«Пересланные сообщения»**.

Чтобы остановить, выключите переключатель.

### 19.5 Журнал событий

Внизу вкладки «Сеть» находится **«Журнал событий»**: всё, что делал транспорт, новые записи сверху. Когда что-то не работает, здесь можно узнать почему. В нём никогда нет ваших сообщений или ваших слов.

#### Как прочитать или очистить журнал событий

1. Откройте вкладку **«Сеть»** и прокрутите вниз.
2. Прочитайте **«Журнал событий»**. Самая новая строка — вверху.
3. Нажмите **«Очистить»** рядом с заголовком, чтобы очистить журнал.

## 20. Резервные копии и переход на новое устройство

### 20.1 Что содержит каждая резервная копия

| Резервная копия | Личность (адрес) | Имя | Контакты | Счётчик использований ключей кошелька | История чатов |
|---|---|---|---|---|---|
| Ваши 24 слова | Да | Нет | Нет | **Нет** | Нет |
| Файл Android **«Создать резервную копию личности…»** (`.pbk`) | Да | Да | Да | **Да** | **Нет** |
| Резервная копия аккаунта Parlons (`.pbk`) | Да | Да | Да | Да | Да |

Файл резервной копии Android **не** содержит историю чатов. Восстановив его на новом телефоне, вы получите свою личность, имя и контакты. Чаты будут пустыми.

### 20.2 Как создать зашифрованную резервную копию (Android)

1. Откройте **«Настройки»** (**три точки**, затем **«Настройки»**).
2. В разделе **«Ключи и безопасность»** нажмите **«Создать резервную копию личности…»**
3. В окне **«Резервная копия личности»** введите пароль не короче 6 символов в поле **«Пароль»** и ещё раз в поле **«Повторите пароль»**. Если вы его потеряете, восстановить его **нельзя**.
4. Нажмите **«ОК»**.
5. Выберите, куда сохранить файл. Предлагаемое имя — `parlons-backup.pbk`.
6. Появится «Резервная копия сохранена».
7. Храните файл в надёжном месте, например на компьютере или USB-накопителе, которые находятся под вашим контролем.

### 20.3 Как снова увидеть свои 24 слова

#### Как показать 24 слова (Android)

1. Убедитесь, что никто не смотрит.
2. Откройте **«Настройки»**. В разделе **«Ключи и безопасность»** нажмите **«Показать сид-фразу»**.
3. Появится окно **«Показать сид-фразу?»** с предупреждением. Нажмите **«Показать»**.
4. Окно **«Запишите эти слова вне сети»** показывает слова. Снимки экрана заблокированы.
5. Когда закончите, нажмите **«Закрыть»**. По возможности не пользуйтесь кнопкой **«Копировать»**; буфер обмена очищается через 60 секунд.

#### Как показать 24 слова (Desktop)

1. Убедитесь, что никто не смотрит.
2. Откройте **«Настройки»**. В разделе **«Ключи и безопасность»** нажмите **«Показать сид-фразу»**.
3. Подтвердите **«Показать сид-фразу?»**.
4. Окно **«Ваша сид-фраза»** показывает слова. Доступна кнопка **«Копировать (очистка через 60 с)»**; записать слова надёжнее.

Или откройте файл с сид-фразой (см. [раздел 5.2](#52-parlons-desktop)).

### 20.4 Переход на новый телефон Android

Одна личность должна работать **в одном месте** одновременно. Переносите её, а не копируйте.

1. На **старом** телефоне создайте зашифрованную резервную копию ([20.2](#202-make-an-encrypted-backup-android)) и скопируйте файл `.pbk` туда, откуда его можно будет достать с нового телефона.
2. Если на старом телефоне были средства, подумайте о том, чтобы сначала перевести их.
3. **Перестаньте пользоваться Parlons на старом телефоне.** Удалите приложение или хотя бы закройте его и больше не открывайте.
4. На **новом** телефоне установите Parlons ([раздел 4.1](#41-android)).
5. На экране приветствия нажмите **«Восстановить по сид-фразе»** и введите свои 24 слова.
6. Откройте **«Настройки»**. В разделе **«Ключи и безопасность»** нажмите **«Восстановить из резервной копии…»**
7. Выберите файл `.pbk`.
8. В окне **«Восстановить из резервной копии»** введите пароль резервной копии в поле **«Пароль»** и нажмите **«ОК»**.
9. Появится окно **«Восстановить эту резервную копию?»** Личность, контакты и чаты на этом телефоне будут заменены данными из резервной копии. Нажмите **«Восстановить»**.
10. Появится «Резервная копия восстановлена — переподключение».

Если файла резервной копии нет, остановитесь после шага 5. Так вы восстановите свою личность. Контакты по-прежнему смогут с вами связаться, потому что ваш адрес остаётся тем же. Чтобы видеть их в своём списке, их нужно будет добавить заново.

Если появится сообщение «Эта резервная копия создана в более новой версии Parlons — сначала обновите приложение.», установите новейшую версию приложения и попробуйте снова.

### 20.5 Восстановление по сид-фразе поверх существующей личности (Android)

Это **заменяет** личность на этом телефоне. Хранящиеся здесь контакты и чаты удаляются, а транспорт перезапускается.

1. Откройте **«Настройки»**. В разделе **«Ключи и безопасность»** нажмите **«Восстановить по сид-фразе»**.
2. Прочитайте предупреждение в окне **«Восстановить по сид-фразе»**.
3. Введите или вставьте фразу в поле **«Введите сид-фразу»**.
4. Для нестандартной фразы Minima отметьте **«Произвольная фраза (Minima anyphrase)»** и введите её в точности.
5. Нажмите **«Восстановить»**.
6. В окне **«Восстановлено»** написано «Ваша личность восстановлена.» Нажмите **«ОК»**.
7. Появится «Личность восстановлена — переподключение».

### 20.6 Перенос Parlons Desktop на новый компьютер

1. Убедитесь, что у вас есть ваши 24 слова.
2. Закройте Parlons Desktop на старом компьютере навсегда (значок в трее, **«Выйти»**).
3. Установите приложение на новый компьютер. При первом запуске оно создаст новую личность.
4. Откройте **«Настройки»**. В разделе **«Ключи и безопасность»** нажмите **«Восстановить по сид-фразе»**.
5. Вставьте свои 24 слова и подтвердите.
6. Появится «Личность восстановлена. Maxima сейчас закроется. Откройте приложение снова, чтобы использовать восстановленную личность.» Приложение закроется.
7. Откройте его снова. Теперь оно использует вашу личность.

Чаты и контакты со старого компьютера таким способом не переносятся. Можно также скопировать всю папку данных `.maxima` со старого компьютера на новый **до** первого запуска; это не задокументированная процедура, поэтому в любом случае храните свои 24 слова в надёжном месте.

### 20.7 Если вы потеряли устройство

- **Потерян телефон с приложением для Android:** восстановите свои слова на новом телефоне. Тот, у кого окажется старый телефон, может прочитать хранящиеся на нём чаты, поэтому сначала переведите средства.
- **Потерян телефон, подключённый к аккаунту Parlons:** отключите этот телефон с другого подключённого устройства ([как отключить устройство](#how-to-revoke-a-lost-device)). Аккаунт и его история не пострадают.
- **Потеряны слова и все устройства:** личность утрачена. Сбросить её нельзя, потому что нет никого, кто мог бы это сделать.

## 21. Один аккаунт на всех устройствах: Parlons Cloud, собственный аккаунт, размещённые аккаунты

Это краткий обзор. Приложение для телефона подробно описано в [руководстве Parlons Cloud](parlons-cloud-portal.md). Работа сервера аккаунтов описана в [руководстве Parlons Node](parlons-node.md).

### Что такое аккаунт Parlons

**Аккаунт Parlons** — это небольшая постоянно работающая программа. Она держит вашу личность в сети, хранит ваши контакты и историю чатов, получает сообщения, пока телефон выключен, и позволяет каждому подключённому устройству видеть одни и те же переписки. Для неё нужен постоянно включённый компьютер с исходящим доступом в интернет: Raspberry Pi, домашний компьютер или небольшой сервер. Проброс портов не нужен.

Получить аккаунт можно тремя способами:

- **Запустить свой.** Одна команда установки на Mac, Linux, Raspberry Pi или Windows. Она выводит ваш адрес и **приглашение** для подключения.
- **Получить размещённый аккаунт.** Тот, у кого есть свой сервер, создаёт для вас аккаунт и даёт вам приглашение.
- **Parlons Node, minimaCore Desktop или minimaDesk** тоже включают аккаунт.

### Как подключить телефон

**Приглашение** — это QR-код или строка текста, начинающаяся с `MAX#`, в которой содержатся адрес аккаунта и одноразовый код подключения.

#### Как установить Parlons Cloud (Android)

1. Откройте на телефоне страницу выпусков: <https://github.com/eurobuddha/maxima/releases>
2. Найдите выпуск с тегом `portal-v0.2.90`.
3. Нажмите на файл `parlons-cloud-portal-0.2.90-release.apk`, чтобы скачать его.
4. Если Android спросит, разрешите установку из браузера, затем нажмите **«Установить»** и **«Открыть»**.

#### Как подключить телефон

1. Откройте **Parlons Cloud** (Android) или приложение для iPhone.
2. На первом экране, **«Parlons в облаке»**, нажмите **«Сканировать QR-код подключения»** и отсканируйте приглашение. Или вставьте его в поле **«Адрес аккаунта или приглашение»**. Адрес и код заполнятся автоматически.
3. Нажмите **«Подключить устройство»**. Появится «Подключение к сети…», затем «Аккаунт найден — подключение…».
4. Разрешите уведомления.
5. На Android откройте **«Настройки»** и в разделе **«Это устройство»** нажмите **«Работать в фоновом режиме»**, если такая кнопка есть.

Если кода нет, оставьте поле **«Код подключения»** пустым и нажмите **«Подключить устройство»**. Приложение сообщит, что запрос на подключение отправлен и его нужно одобрить с уже подключённого устройства. Одобрите его на устройстве, которое уже подключено (см. следующие шаги).

#### Как одобрить устройство, ожидающее подключения

1. На уже подключённом телефоне откройте вкладку **«Узел»**.
2. Прокрутите до **«Ожидают подтверждения (N)»**. В каждой записи написано **«Устройство запрашивает подключение»** и указан его ключ.
3. Проверьте, что ключ совпадает с тем, который показывает новое устройство.
4. Нажимайте **«Разрешить»**, только если он совпадает.

#### Как подключить другое устройство с уже подключённого телефона

1. На подключённом телефоне откройте вкладку **«Узел»**.
2. Нажмите **«Подключить другое моё устройство»**.
3. Если приложение покажет **«Пригласить устройство»**, введите пароль администратора аккаунта и нажмите **«Продолжить»**.
4. Приложение покажет **«Создан новый код подключения»**. Нажмите **«Копировать приглашение»** или **«QR»**, чтобы показать его в виде QR-кода.
5. На новом устройстве выполните шаги из раздела [«Как подключить телефон»](#how-to-pair-a-phone).

О пароле администратора рассказано в [руководстве Parlons Cloud](parlons-cloud-portal.md#10-adding-more-devices-owner-invitations).

#### Как отключить потерянное устройство

1. На телефоне, который всё ещё подключён, откройте вкладку **«Узел»**.
2. Прокрутите до **«Подключённые устройства (N)»** и найдите потерянное устройство.
3. Нажмите **«Отозвать»**.
4. Прочитайте **«Отозвать доступ устройства?»** и нажмите **«Отозвать»**.

#### Как отключить этот телефон

1. В Parlons Cloud нажмите **«Ещё»**, затем **«Отключить это устройство»**.
2. Прочитайте **«Отключить это устройство?»** и нажмите **«Отключить»**. Приложение вернётся на первый экран.
3. На другом подключённом устройстве отзовите запись этого телефона ([«Как отключить потерянное устройство»](#how-to-revoke-a-lost-device)).

Ваш аккаунт и личность остаются на компьютере, где работает аккаунт.

### Что показывает Parlons Cloud

- **«Чаты»** и **«Контакты»**, как в приложении для Android. Ваш адрес показан как **«Мой адрес Parlons Cloud»**. Он одинаков на всех устройствах.
- **«Узел»**: время работы аккаунта, ретрансляторы, подключённые устройства (потерянное можно **«Отозвать»**), устройства, ожидающие одобрения, и **«Подключить другое моё устройство»** для нового кода подключения.
- **«Настройки»**: имя, отчёты о прочтении, блокировка приложения, уведомления, ретрансляторы, с которых начинает телефон, **«Показать сид-фразу»**, **«Создать резервную копию аккаунта…»** (зашифрованный файл `.pbk` со всем аккаунтом, включая историю чатов) и **«Импортировать личность или резервную копию…»**.

Пошаговое описание всех экранов Parlons Cloud см. в разделе [«Подключение приложения к аккаунту»](parlons-cloud-portal.md#4-pair-the-app-to-your-account) и в остальных разделах [руководства Parlons Cloud](parlons-cloud-portal.md).

### Размещённые аккаунты: что может и чего не может владелец сервера

- Владелец сервера **не может** читать ваши сообщения при передаче.
- Владелец сервера **может** читать то, что хранится на его компьютере, включая историю ваших чатов. Выбирайте того, кому доверяете так же, как человеку, который хранит ваш почтовый ящик.
- Уйти можно в любой момент. Создайте резервную копию аккаунта и восстановите её на своём компьютере. Ваш адрес останется тем же.

В размещённых гостевых аккаунтах есть **только чаты, звонки и файлы**: нет кошелька, терминала и управления сервером.

#### Как создать резервную копию аккаунта Parlons

1. В Parlons Cloud нажмите **«Ещё»**, затем **«Настройки»**.
2. В разделе **«Ключи и резервные копии»** нажмите **«Создать резервную копию аккаунта…»**.
3. Дважды введите пароль не короче 6 символов. Если вы его потеряете, восстановить его нельзя.
4. Нажмите **«Создать резервную копию»**, затем выберите, куда сохранить файл `.pbk`.

Чтобы перенести аккаунт на свой компьютер, выполните шаги из раздела [«Как восстановить аккаунт на своём компьютере»](parlons-cloud-portal.md#how-to-restore-an-account-on-your-own-machine).

## 22. Безопасность и конфиденциальность

### Ваши 24 слова

- Это ваша личность **и** кошелёк Minima. Любой, кто их прочитает, может выдать себя за вас и потратить ваши средства.
- Запишите их на бумагу, когда они показаны. Храните листок вне сети.
- Никогда не фотографируйте их, не отправляйте по электронной почте и не вводите в другие приложения или на сайтах.
- Parlons запрашивает их только при восстановлении. Никто из Parlons никогда не попросит их у вас.
- Одна личность должна работать в одном месте одновременно. Если восстановить те же слова на втором устройстве, пока работает первое, это запутает ваших контактов и может привести к повторному использованию ключей кошелька, которые нельзя использовать повторно.

### Что защищает Parlons

- **Содержимое сообщений.** Запечатано сквозным шифрованием и подписано отправителем. Ретрансляторы видят только запечатанный блок данных и ключ маршрутизации.
- **Группы.** Каждое сообщение запечатывается отдельно для каждого участника.
- **Подделка.** Сообщение принимается, только если его подпись соответствует отправителю.
- **Повторы.** Дубликаты и устаревшие сообщения отклоняются.
- **Экраны с вашими словами.** На экранах сид-фразы, восстановления и резервного копирования снимки экрана заблокированы.

### От чего Parlons не защищает

- **Человек, у которого в руках ваше разблокированное устройство.** Хранящиеся на нём чаты там можно прочитать. Используйте блокировку устройства, а на Android — **«Блокировку приложения»**.
- **Человек, у которого есть ваши 24 слова.** Это вы.
- **Владелец сервера, читающий то, что хранится на его компьютере**, — для размещённого аккаунта.
- **Анализ трафика ретранслятором.** Ретранслятор знает, какие ключи маршрутизации с ним связываются, но не знает, о чём идёт речь. Использование нескольких ретрансляторов, как это делает Parlons, ограничивает то, что видит каждый из них.
- **Прямые соединения раскрывают IP-адреса.** Звонки, приватные файлы и прямая доступность соединяют устройства напрямую, поэтому другая сторона может видеть ваш интернет-адрес.
- **Добавленный вами контакт.** Добавляйте только тех, кого действительно хотите.

### Конфиденциальность

Авторы **ничего** не собирают. Нет аналитики, нет сервиса отчётов о сбоях, нет рекламного идентификатора, нет отслеживания, нет сторонних SDK и нет аккаунта, в котором нужно регистрироваться.

- Приложение для Android и Parlons Desktop хранят вашу личность, контакты и чаты на устройстве.
- Parlons Cloud на телефоне хранит только ключ устройства и кэш. Всё остальное хранит аккаунт.
- **Пробуждение iPhone.** iOS не может поддерживать фоновое соединение. Когда приложение для iPhone закрыто, ваш аккаунт отправляет сигнал пробуждения без содержимого («сообщение» или «звонок», без отправителя, без получателя, без текста) через небольшой ретранслятор, который запускает издатель приложения, в службу push-уведомлений Apple. Это можно отключить в приложении для iPhone: «Настройки» → «Уведомления».

## 23. Решение проблем

### Типичные исправления, шаг за шагом

#### Как исправить запаздывание сообщений (Android)

1. Откройте **«Настройки»** (**три точки**, затем **«Настройки»**).
2. В разделе **«Узел и питание»** проверьте **«Исключение из оптимизации батареи»**. Если там написано **«не настроено»**, нажмите **«Настроить батарею»** и разрешите Parlons работать без ограничений.
3. Убедитесь, что уведомления разрешены ([раздел 17](#17-notifications)).
4. Откройте вкладку **«Сеть»**. Проверьте, что в **«Подключённые узлы»** указано 1 или больше.
5. Если там 0, нажмите **«Автоподключение»**.

#### Как снова выйти в сеть

1. Откройте вкладку **«Сеть»**.
2. Нажмите **«Автоподключение»** и дождитесь завершения.
3. Если вы всё ещё не в сети, проверьте, есть ли интернет на телефоне или компьютере.
4. На Android нажмите **«Управление»** и убедитесь, что **«Использовать встроенные ретрансляторы»** включено. В Desktop проверьте, что на переключателе встроенных ретрансляторов написано «Встроенные ретрансляторы: включены».
5. Если вы знаете работающий ретранслятор, добавьте его ([раздел 19.2](#192-relays-hosts)).
6. Причину можно найти в **«Журнале событий»** внизу вкладки.

#### Как исправить отсутствие камеры или микрофона (Android)

1. Откройте приложение **«Настройки»** Android.
2. Перейдите в **«Приложения»**, затем **Parlons!**, затем **«Разрешения»**. (Названия немного различаются у разных производителей телефонов.)
3. Разрешите **«Камера»** и **«Микрофон»**.
4. Вернитесь в Parlons и попробуйте снова.

### Сообщения и контакты

| Признак | Решение |
|---|---|
| «Представление отправлено», но контакт так и не появляется | Устройство собеседника выключено или недоступно. Рукопожатие завершится, когда оно снова будет в сети. Если этого так и не происходит, попросите собеседника добавить вас самому. |
| «Это не адрес Parlons» / «Это не похоже на адрес Parlons» | Адрес должен начинаться с `Mx` или `MAX#`. Скопируйте его ещё раз, полностью. |
| Сообщения приходят с опозданием или только когда я открываю приложение (Android) | **«Настройки»** → **«Узел и питание»** → **«Настроить батарею»**. Проверьте, что на вкладке **«Сеть»** подключён хотя бы один узел. Разрешите уведомления. |
| Одна галочка так и не становится двумя | Другое устройство ещё не подтвердило получение. Оно выключено, или приложение собеседника закрыто системой в фоне. Сообщение ждёт; оно не потеряно. |
| Красный крестик на моём сообщении | Ни один ретранслятор не принял сообщение. Оно остаётся в папке исходящих, и попытки повторяются. Проверьте подключение к интернету и вкладку «Сеть». |
| Значок состояния показывает «не в сети» | Ни один ретранслятор не держит для вас подключение. Приложение переподключится само. Если это продолжается, откройте вкладку «Сеть» и проверьте, что **«Использовать встроенные ретрансляторы»** включено, или добавьте известный вам ретранслятор. |
| «Не удалось определить IP-адрес для обмена» | Вы не в сети. Подключитесь и снова откройте **«Поделиться моим адресом»**. |
| Адрес не показан: «Адреса пока нет — ожидание узла» | Приложение ещё подключается. Подождите несколько секунд. |
| Контакт на классической Maxima не может получить моё голосовое сообщение или звонок | Для голосовых сообщений и звонков Parlons должен быть у обеих сторон. Отправьте текст. |
| Я хочу, чтобы человек перестал мне писать | Удаление контакта убирает его только из вашего списка. Писать вам он по-прежнему может. |

### Медиафайлы и файлы

| Признак | Решение |
|---|---|
| «Слишком большой файл: сообщение может содержать не более 16 МБ» | Отправьте его как **приватный файл** (до 512 МБ). |
| «Фото недоступно · нажмите, чтобы повторить» | Нажмите на него. Устройство отправителя или ретрансляторы могут быть не в сети; попробуйте позже. |
| «Обновите Parlons, чтобы открыть этот файл» / «Приватный файл · обновите Parlons для открытия» | Установите новейшую версию. У обеих сторон должна быть версия с поддержкой приватных файлов. |
| Приватный файл остаётся в состоянии «Ожидание участников» | Кто-то, у кого есть файл, должен быть в сети и доступен. Попросите отправителя открыть Parlons. Если никто в чате не доступен напрямую и не находится в вашей локальной сети, передача не может начаться. |
| «Подготовка прервана» | Удалите передачу и выберите файл снова. |
| «Выберите файл размером до 512 МБ» | Файл слишком велик для приватного файла. |
| Камера или «Сканировать QR-код» не реагирует | Разрешите доступ к камере, когда появится запрос. Разрешение запрашивается при первом сканировании. |
| «Не удалось записать» / «Микрофон недоступен» | Разрешите Parlons доступ к микрофону в настройках Android. |

Проверьте, что телефон не в беззвучном режиме и не в режиме «Не беспокоить». |

| Признак | Решение |

| «Примечание: контрольной суммы BIP39 нет» | Это нормально для фразы из узла Minima. |

## 24. Глоссарий

| Термин | Значение |
|---|---|
| **Parlons!** | Приложение для приватного общения. Есть версии для Android, компьютера и iPhone. |
| **Maxima** | Слой обмена сообщениями, на котором работает Parlons. Совместим по протоколу с классической Maxima в Minima. |
| **Minima** | Блокчейн, на котором работает ваш кошелёк. Так же называется и его собственная монета. |
| **MxUSD** | Токен Minima, привязанный к доллару. Идентификатор токена `0x7D39745FBD29049BE29850B55A18BF550E4D442F930F86266E34193D89042A90`. |
| **Личность** | Ваша пара ключей, полученная из ваших 24 слов. Это то, кем вы являетесь в Parlons. |
| **Сид-фраза / 24 слова** | Слова, которые создают вашу личность и ваш кошелёк. Тот, у кого они есть, — это вы. |
| **Произвольная фраза (anyphrase)** | Нестандартная фраза Minima, которая используется в точности так, как введена, включая заглавные буквы и пробелы. |
| **Адрес** | То, по чему люди с вами связываются. `Mx<key>@<host>:<port>` меняется вместе с ретранслятором; `MAX#<key>#<location service>` — постоянный. |
| **Открытый ключ** | Часть `Mx` вашего адреса и полный «maxima publickey» в «Настройках». Им можно безопасно делиться. |
| **Ретранслятор / узел** | Публичный узел Maxima, который держит для вас открытое подключение и передаёт запечатанный трафик. Читать ваши сообщения он не может. |
| **Мультихоминг** | Подключение сразу к нескольким ретрансляторам, чтобы отказ одного не отрезал вас от сети. |
| **Служба расположения (MLS)** | Справочник, который отвечает на вопрос «какой текущий адрес у этой личности?». Закреплённая служба даёт вам постоянный адрес `MAX#`. |
| **Представление** | Рукопожатие, которое добавляет контакт. Контакт появляется, когда его устройство ответит. |
| **Почтовый ящик** | Запечатанные сообщения, которые хранятся для человека не в сети и передаются ему, когда он вернётся. |
| **Папка исходящих** | Ваши собственные сообщения, ожидающие, пока их примет ретранслятор. |
| **Галочки** | Состояние сообщения: отправляется, отправлено (принято ретранслятором), доставлено (есть на устройстве получателя), прочитано. |
| **Отчёты о прочтении** | Необязательная функция. Сообщает контактам, что вы прочитали их сообщения. По умолчанию выключена. |
| **Группа** | Чат до 12 человек, включая вас. Каждое сообщение запечатывается для каждого участника. |
| **Администратор** | Участник группы, который может изменять её состав. |
| **Приватный файл** | Зашифрованный файл размером до 512 МБ, которым участники чата обмениваются напрямую. |
| **Доступен напрямую** | У вашего устройства есть настоящий публичный адрес, проверенный извне, поэтому контакты связываются с вами без ретранслятора. |
| **NAT операторского уровня (CGNAT)** | Ситуация, когда интернет-провайдер использует один публичный адрес для многих клиентов. Никакой проброс порта его не откроет. |
| **Помогать сети** | Переключатель на Android, который позволяет телефону хранить почту, отвечать на поиски, а при зарядке и подключении к Wi-Fi — работать ретранслятором. |
| **Использования подписей / ключей** | Кошельки Minima подписывают одноразовыми ключами. Счётчик гарантирует, что ключ никогда не будет использован повторно. Он только растёт. |
| **Резервная копия `.pbk`** | Зашифрованный файл резервной копии Parlons, защищённый вашим паролем. |
| **Аккаунт Parlons** | Постоянно работающая программа, которая хранит вашу личность, чтобы ею могли пользоваться многие устройства. |
| **Parlons Cloud** | Приложение (Android или iPhone), которое подключается к аккаунту Parlons. Собственной личности в нём нет. |
| **Приглашение / код подключения** | QR-код или текст `MAX#` с адресом аккаунта и одноразовым кодом, который используется для подключения устройства. |
| **Размещённый аккаунт** | Аккаунт Parlons, который кто-то другой запускает для вас на своём компьютере. |
| **Parlons Node** | Серверный пакет: полноценный узел Minima, ретранслятор и аккаунт Parlons в одном. |
| **Классический движок** | Возможность маршрутизации через классическую Maxima. Большинству людей стоит оставить его выключенным. |
| **Основной узел** | Метка для постоянно включённого устройства. Она меняет только то, что видят контакты. |
| **KeetChat** | Контакты из подключённого узла minimaCore Desktop. Требует, чтобы этот узел работал на том же компьютере. |
| **minimaDocs** | Отдельное приложение для документов, которое можно подключить к аккаунту Parlons в «Настройках». |
