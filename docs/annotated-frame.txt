THE TWO HASHES - same shape, different objects, easy to confuse
  --------------------------------------------------------------------------------------------------------
  msgid      = SHA3-256(MaximaMessage) = 0xD4DA0F4A87C4E9C09D4CF9EA97D20F61ED3C02DD5D34C24754C55C4CF6F759FD
               both peers derive this identically -> dedup key
  customHash = SHA3-256(MaximaPackage) = 0x74711B0DEB85447E7EAFD965AA8BFF19E7DA5A532C9012405D7D9CAE18337350
               sits in the TxPoW header; the ONLY thing a receiver verifies
